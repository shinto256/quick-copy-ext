# Quickstart: 項目カードの並び替えハンドルの検証手順

## 前提

- Google Chrome（またはEdge）114以降。
- リポジトリを取得済み、`npm install` 実行済み。
- 本feature実装後の状態。`chrome://extensions` で拡張機能を読み込み・再読み込み済み。
- 同一グループ内に**項目を5件以上**登録しておく。値の長さが異なるもの（1行のものと複数行になるもの）を
  混ぜること。
- グループも3個以上登録しておく（セクション4のグループ側の回帰確認に使う）。

---

## 1. 掴み手の表示（User Story 2 / SC-001, SC-005, SC-006）

1. 項目一覧の各カードを確認する → **カードの左端に掴み手のアイコン（`⠿`）が表示されている**ことを
   確認する（FR-001 / SC-001）。
2. 全グループパネルを開き、縦リストの行の掴み手と見比べる → **同じ字形・同じ配色**であることを
   確認する（FR-002）。
3. 掴み手の追加前と後でカードの高さを見比べる（実装前のスクリーンショットがなければ、
   掴み手を含む行と含まない行の高さが揃っていることで代替する）→ **カードの高さが変わっていない**
   ことを確認する（FR-004 / SC-006）。
4. 検索欄にキーワードを入力する → **掴み手が表示されない**ことを確認する（FR-003）。
5. 検索欄を空にする → 掴み手が再び表示されることを確認する。
6. その他メニューから「選択」で選択モードに入る → **掴み手が表示されない**ことを確認する（FR-003）。
7. 選択モードを終了する → 掴み手が再び表示されることを確認する。
8. `Tab` でフォーカスを進める → **掴み手にフォーカスが当たらない**ことを確認する（FR-005）。
   カード → コピーボタン → 三点リーダー → 次のカードの順に進むこと。

---

## 2. 掴み手からの並び替え（User Story 2 / SC-003）

1. カード左端の**掴み手を押して**上下に動かす → 移動先のカードが退避して挿入位置が示され、
   カードが浮いて見えることを確認する（FR-012）。
2. 目的の位置で離す → **並び替えが確定する**ことを確認する（FR-006 / SC-003）。
3. 値の長さが異なるカードを混ぜた状態で並び替える → 退避と吸着がずれないことを確認する
   （SC-006。掴み手の追加でカードの高さが変わっていないこと）。
4. 一覧が画面に収まらない状態で、掴み手を掴んだままウィンドウの上端・下端へ寄せる →
   サイドパネル全体がスクロールすることを確認する（FR-012）。
5. **掴み手を押して動かさずに離す** → **並び替えも値のコピーも起きない**ことを確認する（FR-011）。
6. 掴み手のアイコンの**字形の少し外側**（アイコンの上下左右の余白部分）を押してドラッグする →
   並び替えが開始されることを確認する（FR-007 / SC-005）。
7. 掴み手を押してドラッグ中に**他のウィンドウへ切り替える** → 並び替えが確定せず、元の順序に
   戻ることを確認する（FR-012）。
8. サイドパネルを閉じて開き直す → 並び替えた順序が保持されていることを確認する。

---

## 3. カード本体からは並び替わらない（User Story 1 / SC-002, SC-004）

**本specの目的そのもの。ここが最重要。**

1. **カード本体**（掴み手・コピーボタン・三点リーダー以外の領域。名前や値の上）を押して、
   ポインタを**大きく上下に動かす** → **並び替えが開始されない**ことを確認する。カードが浮かず、
   他のカードも退避しないこと（FR-008 / SC-002）。
2. そのまま離す → **並び替えも値のコピーも起きない**ことを確認する（FR-009）。
3. カード本体を押して**動かさずに離す** → **従来どおり値がコピーされ**、コピー完了の表示が出ることを
   確認する（FR-010 / SC-004）。
4. 手順1〜3を5回程度繰り返す → コピーのたびに順序が変わらないことを確認する（SC-002）。
   **実装前は、この操作でポインタがわずかに動くと並び替わっていた。**
5. コピーボタンを押す → 値がコピーされ、並び替えは起きないことを確認する。
6. 三点リーダーを押す → メニューが開き、並び替えもカードのコピーも起きないことを確認する。
7. 選択モードに入り、チェックボックスを押す → 選択が切り替わり、並び替えもコピーも起きないことを
   確認する。

## 4. 回帰確認（SC-007, SC-008）

### キーボードによる並び替え（変更していない）

1. `Tab` でカードにフォーカスし、`Alt` + `↑` / `↓` を押す → **従来どおり並び替えられる**ことを
   確認する（FR-013 / SC-007）。掴み手の追加が影響していないこと。
2. カードにフォーカスして `Enter` / `Space` を押す → 従来どおり値がコピーされることを確認する。
3. 先頭のカードで `Alt` + `↑`、末尾のカードで `Alt` + `↓` を押す → 順序が変わらず、エラーも
   出ないことを確認する。
4. 検索絞り込み中・選択モード中に `Alt` + `↑` を押す → 並び替えが行われないことを確認する。

### グループの縦リスト（変更していない）

5. 全グループパネルを開き、**行のどこを押してもドラッグで並び替えられる**ことを確認する
   （FR-014 / SC-008）。**カードと違い、行本体からドラッグできるのが正しい挙動。**
6. 行を押して動かさずに離す → 従来どおりグループが切り替わることを確認する（FR-014）。
7. 行にフォーカスして `Alt` + `↑` / `↓` を押す → 従来どおり並び替えられることを確認する。
8. 行の三点リーダーから名称変更・削除、パネル内のグループ追加が従来どおり動くことを確認する。

### その他

9. 項目の登録・編集・削除、マスク表示の切替、項目名検索、選択モードによる一括削除・
   一括グループ変更が従来どおり動作すること。
10. オーバーレイのフォーカストラップと `Escape` での復帰が動作すること。
11. テーマの自動追従とライト/ダークの手動固定が動作すること。

---

## 5. 自動テストの実行

```bash
npm test
```

- 既存テストがすべてパスすること（回帰なし）。本featureは storage層を変更せず、純関数の追加もない。
- `dragReorder` の変更分はDOM操作が中心のため、既存specと同方針でユニットテスト対象外とし、
  上記1〜4の手動検証で担保する。
