# Quickstart: 選択項目グループ一括変更・選択モード中の個別操作制限の検証手順

## 前提

- Google Chrome（またはEdge）114以降。
- リポジトリを取得済み、`npm install`実行済み。
- 本feature実装後の状態。`chrome://extensions`で拡張機能を読み込み・再読み込み済み。
- 複数のグループと、各グループに複数項目が登録済みであること。

## 1. 選択モード中の個別操作無効化を確認（User Story 1 / SC-001）

1. あるカードの三点リーダーボタンを押し、個別メニュー(編集・削除)を開いた状態にしておく。
2. ヘッダーの「その他メニュー」から「選択」を選ぶ → 選択モードが開始されると同時に、開いていた
   個別メニューが自動的に閉じることを確認する。
3. 任意のカードのコピーボタンを押す → 値がコピーされず、コピー完了表示も出ないことを確認する。
4. 任意のカードの三点リーダーボタンを押す → 個別メニューが開かないことを確認する。
5. チェックボックスで複数項目を選択する → 選択操作自体は通常どおり行えることを確認する。
6. 「キャンセル」操作で選択モードを終了する → 各カードのコピーボタン・三点リーダーボタンが
   再び操作可能に戻ることを確認する。

## 2. グループ一括変更を確認（User Story 2 / SC-002, SC-003, SC-004）

1. 異なるグループに属する項目を含めて、選択モードで3件以上を選択する。
2. 選択ツールバーの「グループ変更」操作を行う → 未分類を含むグループ一覧から選べる選択UIが
   表示されることを確認する。
3. 変更先グループを選び「適用」する → 選択したすべての項目のグループが変更先に更新され、
   一覧・グループ絞り込み表示に即座(体感1秒以内)に反映されることを確認する。
4. 選択していなかった項目のグループが変更されていないこと、選択モードが終了し通常表示に
   戻っていることを確認する。
5. 再度選択モードに入り、「グループ変更」→変更先を選ぶ→「キャンセル」を行う → 項目のグループが
   変更されず、選択状態も維持されていることを確認する。
6. 何も選択していない状態(選択件数0件)で「グループ変更」操作を試みる → 操作が無効化されており
   実行できないことを確認する。

## 3. 自動テストの実行

```bash
npm run test
```

- 既存テストがすべてパスすること(回帰なし)。
- 新規: `itemRepository.test.js`に追加した`updateGroupMany`のテスト
  （[[contracts/item-repository-additions.md]] 参照）がパスすること。
