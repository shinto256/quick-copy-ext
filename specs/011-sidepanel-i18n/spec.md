# Feature Specification: サイドパネルの多言語対応（日本語・英語・中国語）

**Feature Branch**: `feature/req-000015`

**Created**: 2026-09-05

**Status**: Draft

**Reqord Requirements**: [[req-000015]] サイドパネルの多言語対応（承認済み・要約は下記「Reqord要件要約」参照）

**Input**: User description: "req-000015「サイドパネルの多言語対応」に基づく仕様作成。概要: サイドパネルのその他メニューに、既存の「テーマ」と同じ形式で「言語」の項目を追加する。日本語・英語・中国語の3択、初期値は日本語。選択した言語は設定として保存され、拡張機能を開き直しても維持される。サイドパネル内の全表示文字列を翻訳可能な形に置き換え、あわせて項目登録フォームの検証エラーが内部の英語識別文字列をそのまま表示している既存の不整合を修正する。"

## Reqord要件要約

- **req-000015（サイドパネルの多言語対応）**: サイドパネルのその他メニュー（右上の三点リーダー）に、既存の「テーマ」と同じ形式で「言語」の項目を追加する。選択できる言語は日本語・英語・中国語の3つで、初期状態は日本語とする。選択した言語はテーマと同様に保存され、拡張機能を開き直しても維持される。現状、サイドパネルの表示文字列はすべて日本語のハードコードであり切り替える仕組みがないため、翻訳可能な形に置き換え、選択した言語に応じて表示する。あわせて、項目登録フォームの保存時検証エラーが`ItemRepository`の内部検証エラーメッセージ（英語の識別文字列）をそのまま利用者に表示している既存の不整合を修正する。全グループパネルの同種のエラーは既に日本語へ変換済みであり、項目登録フォーム側だけが取り残されている。Chrome Web Store上の拡張機能名・説明文（`manifest.json`）はブラウザの言語設定に紐づく別の仕組みであり、本要件の対象外とする。

本specは `002-side-panel-ui` で実装済みのその他メニュー（テーマ設定・選択モード開始）に「言語」セクションを追加し、`001-quick-copy-items` から積み上げられたサイドパネルの全表示文字列を翻訳可能な形に置き換える。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - その他メニューから言語を切り替える (Priority: P1) 🎯 MVP

利用者は、その他メニューの「テーマ」の下に「言語」の項目を見つけ、日本語・英語・中国語のいずれかを選ぶ。選んだ言語は即座に反映され、サイドパネルを閉じて開き直しても保持される。

**Why this priority**: 言語を切り替える仕組みそのものであり、これがなければ翻訳した文字列を提供する意味がない。既存のテーマ切替と同じ操作感で提供することで、利用者が新しい操作を覚える必要をなくす。

**Independent Test**: その他メニューを開いて「言語」セクションが表示されていることを確認し、日本語以外を選んで表示が切り替わること、サイドパネルを閉じて再度開いても選んだ言語のまま起動することを確認する。

**Acceptance Scenarios**:

1. **Given** その他メニューを開いた、**When** 表示を確認する、**Then** 「テーマ」セクションの下に「言語」セクションがあり、日本語・英語・中国語の3つの選択肢がある。
2. **Given** 「言語」セクションを表示している、**When** 現在選択中の言語を確認する、**Then** 初期状態では「日本語」が強調表示されている。
3. **Given** その他メニューが開いている、**When** 「English」を選ぶ、**Then** その他メニュー自体を含むサイドパネルの表示が英語に切り替わり、「English」が強調表示される。
4. **Given** 言語を英語に切り替えた、**When** サイドパネルを閉じて再度開く、**Then** 英語表示のまま起動する。
5. **Given** 言語を一度も選択していない、**When** 初めてサイドパネルを開く、**Then** 日本語で表示される。
6. **Given** 言語を切り替えた、**When** その他メニューを再度開く、**Then** メニューの見出しやボタン自体も切り替えた言語で表示されている。

---

### User Story 2 - サイドパネル全体が選んだ言語で表示される (Priority: P1)

利用者は言語を切り替えたあと、検索・項目一覧・タブ・全グループパネル・選択モード・確認ダイアログなど、サイドパネルのどの画面を開いても選んだ言語で表示されることを期待する。一部だけ日本語のまま残っていると、切り替えた意味が薄れる。

**Why this priority**: User Story 1 で切り替えの仕組みが動いても、翻訳が一部の画面にしか及んでいなければ機能として不完全になる。両方が揃って初めて「言語を切り替えられる」という価値になる。

**Independent Test**: 英語・中国語それぞれに切り替えた状態で、検索欄・項目の追加と編集・項目カードの操作・タブ・全グループパネル・選択モードの一括操作・各種確認ダイアログを開き、日本語の文字列が残っていないことを確認する。

**Acceptance Scenarios**:

1. **Given** 言語を英語に切り替えた、**When** 検索欄・マスク切替・項目追加ボタンを確認する、**Then** それぞれのラベルとプレースホルダーが英語で表示されている。
2. **Given** 言語を英語に切り替えた、**When** 項目登録フォームを開く、**Then** 各項目のラベル・グループの「未分類」・保存とキャンセルのボタンが英語で表示されている。
3. **Given** 言語を英語に切り替えた、**When** 項目カードとその操作（コピー・編集・削除・掴み手）を確認する、**Then** ラベルと確認ダイアログの文言が英語で表示されている。
4. **Given** 言語を英語に切り替えた、**When** タブと全グループパネル（絞り込み・名称変更・削除・追加・件数表示）を確認する、**Then** すべて英語で表示されている。
5. **Given** 言語を英語に切り替えた、**When** 選択モードに入り選択件数・一括削除・一括グループ変更を確認する、**Then** すべて英語で表示されている。
6. **Given** 言語を中国語に切り替えた、**When** User Story 2 のシナリオ1〜5と同じ操作を行う、**Then** すべて中国語で表示されている。
7. **Given** 言語を切り替えた直後に選択モード中だった、**When** 表示を確認する、**Then** 選択状態と選択件数は保たれたまま、文言だけが新しい言語に切り替わっている。
8. **Given** 項目登録フォームに入力中に言語を切り替えた、**When** フォームを確認する、**Then** 入力していた値は保たれたまま、ラベルだけが新しい言語に切り替わっている。
9. **Given** 全グループパネルを開いた状態で言語を切り替えた、**When** パネルを確認する、**Then** パネルは開いたままで、表示文言だけが新しい言語に切り替わっている。

### User Story 3 - 項目登録フォームの検証エラーが読める言語で表示される (Priority: P2)

利用者が項目名や値を上限文字数を超えて入力し保存しようとすると、検証エラーが表示される。現状はこのエラーが内部の英語識別文字列（例: `name must be 1-50 characters`）のまま表示されており、日本語表示中であっても意味が読み取れない。選んでいる言語に応じた読める文言にしたい。

**Why this priority**: 既存の不整合の修正であり、多言語対応の一部として直す必要はあるが、User Story 1・2（切替の仕組みと画面全体の翻訳）が成立すれば機能の骨格は完成する。エラー文言の是正は影響範囲が保存操作時のみに限られるためP2とする。

**Independent Test**: 項目名を空のまま、または上限文字数を超えて保存しようとし、表示されるエラーメッセージが選択中の言語で意味の通る文言であることを確認する。日本語・英語・中国語それぞれで確認する。

**Acceptance Scenarios**:

1. **Given** 日本語表示で項目名を空のまま保存しようとした、**When** エラーを確認する、**Then** 「name must be 1-50 characters」のような内部識別文字列ではなく、日本語として意味の通る文言が表示される。
2. **Given** 英語表示で同じ操作をした、**When** エラーを確認する、**Then** 英語として意味の通る文言が表示される。
3. **Given** 中国語表示で同じ操作をした、**When** エラーを確認する、**Then** 中国語として意味の通る文言が表示される。
4. **Given** 値を上限文字数を超えて入力し保存しようとした、**When** エラーを確認する、**Then** 名前の場合と同様に選択中の言語で意味の通る文言が表示される。
5. **Given** 登録件数が上限に達した状態で新規保存しようとした、**When** エラーを確認する、**Then** 選択中の言語で意味の通る文言が表示される。

---

### Edge Cases

- 保存されている言語設定の値が"ja"・"en"・"zh"のいずれでもない場合は、日本語として扱う。
- 全グループパネルや項目登録フォームが開いた状態で言語を切り替えても、開閉状態は変わらない（User Story 2 シナリオ8・9）。
- 選択モード中に言語を切り替えても、選択状態は失われない（User Story 2 シナリオ7）。
- その他メニューが開いた状態で言語を切り替えた場合、メニュー自体も新しい言語で再表示され、開いたままになる（User Story 1 シナリオ6）。
- 項目名や値に利用者が入力した文字列（項目名・値そのもの）は翻訳の対象ではない。翻訳の対象はサイドパネルの画面構成要素（ラベル・ボタン・メッセージ）に限る。

## Requirements *(mandatory)*

### Functional Requirements

#### 言語の切替

- **FR-001**: システムは、その他メニューに「テーマ」セクションと同じ形式の「言語」セクションを表示しなければならない。
- **FR-002**: システムは、言語の選択肢として日本語・英語・中国語の3つを提供しなければならない。
- **FR-003**: システムは、現在選択中の言語を「言語」セクション内で強調表示しなければならない。
- **FR-004**: システムは、言語が選択された場合、選択した言語を保存し、サイドパネルの表示を再読み込みなしに選択した言語へ切り替えなければならない。
- **FR-005**: システムは、言語が一度も選択されていない場合、日本語で表示しなければならない。
- **FR-006**: システムは、拡張機能を開いたとき、直前に保存されている言語で表示しなければならない。
- **FR-007**: システムは、保存されている言語の値が日本語・英語・中国語のいずれでもない場合、日本語として扱わなければならない。

#### 表示範囲

- **FR-008**: システムは、サイドパネルのヘッダー（検索欄・マスク切替・項目追加ボタン・その他のメニューを開くボタン）の表示文字列を、選択した言語で表示しなければならない。
- **FR-009**: システムは、項目登録フォーム（各項目のラベル・グループ選択の「未分類」・保存とキャンセルのボタン・空状態の文言）の表示文字列を、選択した言語で表示しなければならない。
- **FR-010**: システムは、項目カード（コピー・編集・削除の各操作、確認ダイアログ）の表示文字列を、選択した言語で表示しなければならない。
- **FR-011**: システムは、タブおよび全グループパネル（絞り込み・名称変更・削除・追加・件数表示・確認ダイアログ）の表示文字列を、選択した言語で表示しなければならない。
- **FR-012**: システムは、選択モード（選択件数・一括削除・一括グループ変更・確認ダイアログ）の表示文字列を、選択した言語で表示しなければならない。
- **FR-013**: システムは、その他メニュー自体（テーマの選択肢・言語の選択肢・選択モード開始の項目）の表示文字列を、選択した言語で表示しなければならない。

#### 状態の保持

- **FR-014**: システムは、言語を切り替えた時点で開いているオーバーレイ（項目登録フォーム・全グループパネル）の開閉状態を変えてはならない。
- **FR-015**: システムは、言語を切り替えた時点で入力中のフォームの値を変えてはならない。
- **FR-016**: システムは、言語を切り替えた時点での選択モードの選択状態を変えてはならない。

#### 検証エラーの表示

- **FR-017**: システムは、項目登録フォームの保存時検証エラーを、選択した言語で意味の通る文言に変換して表示しなければならない。内部の検証エラー識別文字列をそのまま表示してはならない。
- **FR-018**: システムは、項目名・値それぞれの文字数超過、および登録件数の上限超過のいずれについても、前項の変換を行わなければならない。

### Key Entities

- **言語設定（Language）**: `001-quick-copy-items` で定義済みの `Settings` に属性を追加する。値は日本語・英語・中国語のいずれかを表す識別子。初期値は日本語。既存の `theme` 属性と対になる位置づけ。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: その他メニューに「言語」の選択項目が表示され、日本語・英語・中国語の3つから選べる。
- **SC-002**: 言語を選択すると、サイドパネル内の表示文字列の100%が選択した言語に切り替わる。
- **SC-003**: 言語設定を保存後、拡張機能を閉じて再度開いても選択した言語が維持される。
- **SC-004**: 初期状態（言語を一度も選択していない状態）でサイドパネルを開くと、日本語で表示される。
- **SC-005**: 項目登録フォームの検証エラーが、選択した言語で意味の通る文言で表示される（内部の英語識別文字列がそのまま表示される事象が0件になる）。
- **SC-006**: 言語の切替によって、開いているオーバーレイの開閉状態・入力中の値・選択モードの選択状態が失われる事象が0件である。

## Assumptions

- 翻訳文字列の管理方法（辞書の構成、参照の仕組み、動的に生成される文字列への適用方法）は計画・実装フェーズで具体化する。
- 件数を含む文言（選択件数、グループの所属項目件数、タブ総数など）の英語・中国語表現は、言語ごとの数の扱い（単数・複数の区別など）を踏まえて計画・実装フェーズで具体化する。日本語・中国語には英語のような単数・複数の文法的区別がないため、この違いを翻訳文字列の設計に反映する。
- 翻訳の対象はサイドパネルの画面構成要素（ラベル・ボタン・メッセージ・確認ダイアログ）に限る。利用者が入力した項目名・値・グループ名そのものは翻訳の対象ではない。
- Chrome Web Store上の拡張機能名・説明文（`manifest.json` の `name` / `description`）は、Chromeが管理するブラウザの言語設定に紐づく別の仕組みであり、本specの対象に含めない。
- 翻訳文の品質（自然さ・専門用語の統一）は実装時に判断する。誤訳や不自然な表現が見つかった場合は、後続の修正で対応する前提とする。
- 既存の設定（テーマ、マスク表示）の保存・読み出しの仕組みと構造は変更しない。言語設定はこれに追加する形で保存する。
