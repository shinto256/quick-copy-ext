# Quickstart: サイドパネルの多言語対応の検証手順

## 前提

- Google Chrome（またはEdge）114以降。
- リポジトリを取得済み、`npm install` 実行済み。
- 本feature実装後の状態。`chrome://extensions` で拡張機能を読み込み・再読み込み済み。
- グループを3個以上、各グループに項目を数件登録しておく。

---

## 1. その他メニューから言語を切り替える（User Story 1 / SC-001, SC-003, SC-004）

1. サイドパネルを開く（初回、言語を選択したことがない状態）→ **日本語で表示される**ことを
   確認する（FR-005 / SC-004）。
2. その他メニューを開く → 「テーマ」セクションの下に**「言語」セクション**があり、
   「日本語」「English」の2つの選択肢があることを確認する（FR-001 / FR-002）。
3. 「日本語」が強調表示されていることを確認する（FR-003）。
4. 「English」を選ぶ → **その他メニュー自体を含むサイドパネルの表示が英語に切り替わり**、
   「English」が強調表示されることを確認する（FR-004、FR-002a: 選択肢の表記自体は
   「日本語」「English」のまま変わらないこと）。
5. その他メニューを閉じて再度開く → メニューの見出し・選択肢が英語のままであることを
   確認する（FR-013）。
6. サイドパネルを閉じて再度開く → **英語表示のまま起動する**ことを確認する（FR-006 / SC-003）。
7. 「言語」から「日本語」に戻す → 日本語表示に戻ることを確認する。

---

## 2. サイドパネル全体が選んだ言語で表示される（User Story 2 / SC-002）

英語に切り替えた状態で、以下を確認する。

1. **ヘッダー**: 検索欄のプレースホルダー、マスク切替のラベル、項目追加ボタンの`title`、
   その他メニューボタンの`title`が英語であることを確認する（FR-008）。
2. **項目登録フォーム**: 項目追加ボタンからフォームを開き、名前・値・グループの各ラベル、
   グループ選択の「Unassigned」、保存・キャンセルのボタンが英語であることを確認する（FR-009）。
3. **項目カード**: コピーボタンの`title`、掴み手を含むカードの操作、三点リーダーから
   「Edit」「Delete」、削除確認ダイアログが英語であることを確認する（FR-010）。
4. **タブと全グループパネル**: タブバーの「Unassigned」、パネルを開くボタンの表記、
   パネル内の絞り込みプレースホルダー・「Rename」「Delete」・削除確認ダイアログ・
   「+ Add group」・件数表示が英語であることを確認する（FR-011）。
5. **選択モード**: その他メニューから「Select」で選択モードに入り、選択件数の表示、
   「Change group」「Delete」「Cancel」、一括削除の確認ダイアログが英語であることを
   確認する（FR-012）。
6. 空の項目一覧・絞り込み結果0件のグループ一覧を表示させ、それぞれの空状態の文言が
   英語であることを確認する。
7. 上記1〜6のいずれの画面にも**日本語の文字列が残っていない**ことを確認する（SC-002）。

---

## 3. 状態が失われない（User Story 2 / SC-006）

1. 選択モードに入り2件選択した状態で、その他メニューから言語を英語に切り替える →
   **選択状態（チェック済みのカード）と選択件数の表示が保たれたまま**、文言だけが英語に
   切り替わることを確認する（FR-016）。
2. 項目登録フォームを開き、名前と値を入力した状態で言語を切り替える →
   **入力していた値が保たれたまま**、ラベルだけが英語に切り替わることを確認する（FR-015）。
3. 全グループパネルを開いた状態で言語を切り替える →
   **パネルが開いたまま**、表示文言だけが英語に切り替わることを確認する（FR-014）。
4. グループの名称変更のインライン編集中に言語を切り替える →
   編集中の入力値が保たれることを確認する。

---

## 4. 項目登録フォームの検証エラー（User Story 3 / SC-005）

1. 日本語表示のまま、項目名を空にして保存しようとする → 内部識別文字列
   （`name must be 1-50 characters` のような英語の技術的な文字列）ではなく、
   **日本語として意味の通る文言**が表示されることを確認する（FR-017 / SC-005）。
2. 英語表示に切り替え、同じ操作をする → **英語として意味の通る文言**が表示されることを
   確認する。
3. 値（複数行の入力欄）を2000文字を超えて入力し保存しようとする → 名前の場合と同様に
   選択中の言語で意味の通る文言が表示されることを確認する（FR-018）。
4. 項目を上限件数まで登録した状態（または `chrome://extensions` の Service Worker
   コンソールから `items` を500件相当に見立てて）新規保存しようとする →
   選択中の言語で意味の通る文言が表示されることを確認する（FR-018）。

---

## 5. 既存機能の回帰確認

1. テーマの自動追従・ライト/ダーク固定の切替が、言語設定と独立して動作すること。
2. マスク表示の切替が動作すること。
3. 項目の登録・編集・削除、ドラッグでの並び替え、キーボード（`Alt` + 矢印）での並び替えが
   動作すること。
4. グループの作成・名称変更・削除・並び替え（ドラッグ・キーボード）・絞り込みが動作すること。
5. タブバーの幅追従表示（`010-tab-overflow`）が言語切替後も正しく動作すること
   （英語は文言が長くなりやすいため、タブの幅計算に影響が出ていないか確認する）。
6. オーバーレイのフォーカストラップと `Escape` での復帰が動作すること。
7. 選択モードによる一括削除・一括グループ変更が動作すること。

---

## 6. 自動テストの実行

```bash
npm test
```

- 既存テストがすべてパスすること（回帰なし）。
- 新規: `tests/unit/i18n.test.js` の `t()` の展開・辞書のキー網羅性のテスト
  （[contracts/i18n-contract.md](./contracts/i18n-contract.md) 参照）がパスすること。
- 追加: `tests/unit/settingsRepository.test.js` の `setLanguage` / `get` の異常値丸めのテスト
  （[contracts/settings-language-contract.md](./contracts/settings-language-contract.md) 参照）が
  パスすること。

`sidepanel.js` / `groupPanel.js` の言語切替の配線（`selectLanguage`、`groupPanel.refresh` の
DOM再描画）はDOM操作が中心のため、既存specと同方針でユニットテスト対象外とし、
上記1〜5の手動検証で担保する。
