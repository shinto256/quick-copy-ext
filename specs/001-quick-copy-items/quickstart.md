# Quickstart: クイックコピー登録・管理機能

**Phase 1 出力**。実装完了後、このガイドに沿ってUser Story 1〜4がエンドツーエンドで動作する
ことを確認する。

## 前提条件

- Google Chrome または Microsoft Edge（最新版）
- Node.js（vitest実行用。拡張機能本体の実行にビルドは不要）

## セットアップ

1. リポジトリのユニットテスト依存をインストールする: `npm install`
2. ユニットテストを実行する: `npm test`（`tests/unit/*.test.js` が全てPASSすること）
3. ブラウザで拡張機能管理ページを開く（Chrome: `chrome://extensions`、Edge: `edge://extensions`）
4. 「デベロッパーモード」を有効にし、「パッケージ化されていない拡張機能を読み込む」で
   リポジトリルート（`manifest.json` のあるディレクトリ）を選択する

## 検証シナリオ

### US1: 項目の登録・保存・編集・削除

1. 拡張機能アイコンから options 画面を開く
2. 名前「住所」、値「東京都千代田区...」（複数行可）を入力して保存する → 一覧に反映されることを確認
3. 名前・値を空のまま保存を試みる → エラーが表示され保存されないことを確認
4. 登録済み項目の名前・値を編集して保存する → 変更が一覧に反映されることを確認
5. 登録済み項目を削除する → 一覧から除外されることを確認

### US2: 一覧表示とコピー（デフォルトマスク表示）

1. popupを開く → 名前は平文、値はマスク記号で表示されることを確認
2. コピー操作を行う → 任意のテキスト欄に貼り付け、値の原文（マスクされていない内容）が
   貼り付けられることを確認

### US3: マスク表示の切替

1. popupで表示切替を操作する → 一覧内の全項目が平文表示に切り替わることを確認
2. popupを閉じて再度開く → 直前の表示状態（平文表示）が維持されていることを確認

### US4: グループによる整理

1. options画面でグループを作成する（例: 「英語住所」）
2. 既存項目に作成したグループを割り当てる
3. popupでそのグループに絞り込む → 割り当てた項目のみが表示されることを確認
4. そのグループを削除する → 項目自体は削除されず「未分類」として一覧に残ることを確認
