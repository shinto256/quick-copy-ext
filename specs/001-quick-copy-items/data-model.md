# Data Model: クイックコピー登録・管理機能

**Phase 1 出力**。永続化先はすべて `chrome.storage.local`（research.md 決定5）。

## Item（登録項目）

| フィールド | 型 | 必須 | 制約 |
|-----------|-----|------|------|
| `id` | string | ✓ | 一意なID（Repositoryが採番） |
| `name` | string | ✓ | 1〜50文字（FR-001, FR-014） |
| `value` | string | ✓ | 1〜2000文字、改行を含む複数行を許容（FR-001, Clarifications 2026-08-27） |
| `groupId` | string \| null | ✓ | 所属グループのID。未所属は `null`（FR-012, FR-013） |
| `createdAt` | string (ISO8601) | ✓ | 作成日時 |
| `updatedAt` | string (ISO8601) | ✓ | 更新日時 |

**バリデーションルール**:

- `name` が空、または51文字以上 → 保存/更新を拒否（FR-002）
- `value` が空、または2001文字以上 → 保存/更新を拒否（FR-002）
- 全体の件数が500件に達している状態での新規作成 → 拒否（FR-003）
- `name` の重複は許容する（一意制約なし。Reqord req-000001ヒアリングで確定）

**関係**:

- `Item.groupId` は `Group.id` を参照する任意（optional）の外部参照。参照先グループが削除
  された場合、`Item.groupId` は `null` に更新される（FR-013）

**状態遷移**: なし（作成・編集・削除のみ。ステータスのようなライフサイクルは持たない）

## Group（グループ）

| フィールド | 型 | 必須 | 制約 |
|-----------|-----|------|------|
| `id` | string | ✓ | 一意なID（Repositoryが採番） |
| `name` | string | ✓ | 1〜30文字（FR-010） |

**バリデーションルール**:

- `name` が空、または31文字以上 → 作成/変更を拒否（FR-010）
- 全体の件数が50件に達している状態での新規作成 → 拒否（FR-011）
- 同名グループの重複作成は許容する（識別は `id` で行う）
- 階層化（親子グループ）は対象外（spec.md Assumptions）

**関係**:

- 1つの `Group` は0個以上の `Item` から参照される（1:N）。`Group` 削除時は参照する
  全 `Item.groupId` を `null` に更新してから `Group` を削除する（FR-013）

## DisplaySetting（表示設定）

| フィールド | 型 | 必須 | 制約 |
|-----------|-----|------|------|
| `maskEnabled` | boolean | ✓ | デフォルト `true`（FR-005, SC-006） |

**バリデーションルール**: なし（真偽値のトグルのみ）

**関係**: なし（拡張機能全体に対する単一のグローバル設定。ユーザーやItem単位の設定は持たない）

**永続化**: `chrome.storage.local` キー `settings` に単一オブジェクトとして保持する
