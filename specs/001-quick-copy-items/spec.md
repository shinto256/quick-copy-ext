# Feature Specification: クイックコピー登録・管理機能

**Feature Branch**: `001-quick-copy-items`

**Created**: 2026-08-27

**Status**: Draft

**Input**: Reqord req-000001〜req-000004（承認済み）/ spec-000001〜spec-000004 を要約した入力。
フォーム入力で繰り返し使う定型文字列（例: 英語住所の「東京都」部分）を、ブラウザ拡張機能に
名前付きで登録し、ワンクリックでコピーできるようにする。値部分はデフォルトでマスク表示され、
表示/非表示の切替やグループでの整理が可能。

## Clarifications

### Session 2026-08-27

- Q: 登録する「値」(コピー対象の文字列)は改行を含む複数行テキストを許容する？ → A: 許容する（住所など複数行の定型文も登録・表示・コピー可能とする）

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 項目の登録・保存 (Priority: P1)

ユーザーは、コピーしたい文字列（値）と、それが何かひと目でわかる名前（ラベル）を入力し、
拡張機能に保存する。例: 名前「住所」、値「東京都...」。

**Why this priority**: 他のすべての機能（一覧表示・コピー・マスク・グループ）が成立する前提。
これがなければ拡張機能に価値がない。

**Independent Test**: 登録フォームに名前と値を入力して保存し、保存後に項目が1件増えている
ことを確認するだけで独立してテストできる。

**Acceptance Scenarios**:

1. **Given** 登録フォームが空の状態、**When** 名前「住所」・値「東京都千代田区...」を入力し保存する、
   **Then** 項目が保存され、一覧に新しい項目として反映される
2. **Given** 名前または値が未入力、**When** 保存を実行する、**Then** 保存は行われずエラーが表示される
3. **Given** 登録済み項目が500件、**When** 501件目を保存しようとする、**Then** 保存は拒否され上限到達が通知される
4. **Given** 登録済み項目が存在する、**When** その項目の名前または値を編集して保存する、**Then** 変更内容が一覧に反映される
5. **Given** 登録済み項目が存在する、**When** その項目を削除する、**Then** 一覧からその項目が除外される

---

### User Story 2 - 一覧表示とコピー（デフォルトマスク表示） (Priority: P2)

ユーザーは、登録済み項目の一覧を開き、名前を見ながら目的の項目のコピー操作を行う。値部分は
デフォルトでマスク表示され、画面を見られても内容がわからないようになっている。コピー操作は
表示状態に関わらず値の原文をコピーする。

**Why this priority**: 「ワンクリックでコピーできる」という本機能の中心的価値そのもの。

**Independent Test**: 登録済み項目がある状態で一覧を開き、値がマスク表示されていること、
コピー操作でクリップボードに原文が入ることを確認して独立にテストできる。

**Acceptance Scenarios**:

1. **Given** 項目が登録済み、**When** 一覧を開く、**Then** 名前は平文、値は固定のマスク記号で表示される
2. **Given** 値がマスク表示中、**When** 項目のコピー操作を行う、**Then** クリップボードには値の原文がコピーされる
3. **Given** 登録済み項目が0件、**When** 一覧を開く、**Then** 「未登録」を示す空状態が表示される

---

### User Story 3 - マスク表示の切替 (Priority: P3)

ユーザーは、画面共有をしていない自席作業時など、内容を確認したい場面でマスクを一時的に解除し、
一覧の値をすべて平文表示に切り替えられる。切替状態は次回起動時も保持される。

**Why this priority**: プライバシー保護（デフォルトマスク）と内容確認のしやすさを両立させる
補助機能。登録・コピーが動作すればMVPとしては成立するため、優先度は3番目。

**Independent Test**: 一覧が表示された状態で表示切替を1回操作し、全項目の値表示が平文⇔マスクで
切り替わること、再度開いても直前の状態が保持されることを確認して独立にテストできる。

**Acceptance Scenarios**:

1. **Given** 値がマスク表示中、**When** 表示切替操作を行う、**Then** 一覧内の全項目が平文表示に切り替わる
2. **Given** 平文表示に切り替えた直後、**When** 拡張機能を閉じて再度開く、**Then** 平文表示の状態が維持されている

---

### User Story 4 - グループによる整理 (Priority: P4)

ユーザーは、登録項目が増えてきた際に、グループを作成して項目を分類し、一覧をグループ単位で
絞り込んで管理しやすくする。

**Why this priority**: 項目数が少ないうちは不要で、登録・コピー・マスクの3機能が動けばMVPとして
成立するため、優先度は最も低い。

**Independent Test**: グループを1件作成し、既存項目をそのグループに割り当てたうえで、一覧を
そのグループで絞り込むと、割り当てた項目のみが表示されることを確認して独立にテストできる。

**Acceptance Scenarios**:

1. **Given** グループが未作成、**When** 新規グループを作成する、**Then** グループ一覧に追加される
2. **Given** 項目とグループが存在する、**When** 項目にグループを割り当てて一覧をそのグループで絞り込む、
   **Then** 割り当てた項目のみが表示される
3. **Given** グループに項目が割り当て済み、**When** そのグループを削除する、**Then** 項目自体は削除されず「未分類」として一覧に残る

---

### Edge Cases

- 名前または値が文字数上限（名前50文字、値2000文字）を超えて入力された場合、保存は拒否されエラーが表示される
- 登録項目が500件に達している状態で追加登録しようとした場合、保存は拒否され上限到達が通知される
- クリップボードへの書き込みが権限拒否等で失敗した場合、コピー失敗が明示的に通知される
- グループ名が文字数上限（30文字）を超えて入力された場合、作成・変更は拒否される
- グループ数が上限（50件）に達している状態で追加作成しようとした場合、作成は拒否される
- 表示切替やマスク設定の保存に失敗した場合、次回起動時にデフォルト状態（マスク表示ON）に
  戻る可能性がある旨が通知される

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: システムは、ユーザーが名前（1〜50文字）と値（1〜2000文字、改行を含む複数行を許容）の組を
  入力して項目として保存できなければならない
- **FR-002**: システムは、名前または値が未入力、または文字数範囲外の場合、保存を拒否しエラーを
  表示しなければならない
- **FR-003**: システムは、登録可能な項目数を最大500件に制限し、上限到達時は保存を拒否しなければならない
- **FR-004**: システムは、登録済み項目の一覧を表示し、名前は常に平文で表示しなければならない
- **FR-005**: システムは、マスク表示が有効な場合、値を文字数によらず固定のマスク記号で表示しなければならない
- **FR-006**: システムは、コピー操作が行われた項目について、表示状態に関わらず値の原文をクリップボードに
  コピーしなければならない
- **FR-007**: システムは、マスク表示の有効/無効をユーザーの操作で切り替えられなければならない
- **FR-008**: システムは、マスク表示の有効/無効の状態を保存し、次回起動時も同じ状態を復元しなければならない
- **FR-009**: システムは、切替操作1回で一覧内の全項目の表示状態を一括して切り替えなければならない
- **FR-010**: システムは、ユーザーがグループ（名前1〜30文字）を作成・名称変更・削除できなければならない
- **FR-011**: システムは、作成可能なグループ数を最大50件に制限し、上限到達時は作成を拒否しなければならない
- **FR-012**: システムは、項目を1つのグループに割り当てられ、一覧をグループ単位で絞り込み表示できなければならない
- **FR-013**: システムは、グループが削除された場合、そのグループに属していた項目を削除せず「未分類」として
  扱わなければならない
- **FR-014**: システムは、登録済み項目の名前・値を編集できなければならない（編集時も文字数制限のバリデーションを適用する）
- **FR-015**: システムは、登録済み項目を削除できなければならない

### Key Entities

- **登録項目 (Item)**: ユーザーが登録する「名前」と「値（コピー対象の文字列。改行を含む複数行を許容）」の組。
  任意で1つのグループに属する。値は表示設定に応じてマスク表示される
- **グループ (Group)**: 登録項目を分類するための名前のみを持つ単位。項目は0または1個のグループに属する
- **表示設定 (Display Setting)**: マスク表示の有効/無効を保持する、拡張機能全体に対する単一の設定

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 項目の保存操作から一覧への反映までが1秒以内に完了する
- **SC-002**: 名前・値の文字数バリデーションについて、範囲内入力は100%保存が許可され、範囲外入力は
  100%エラーとなる
- **SC-003**: 登録上限（500件）到達後の追加保存操作は100%拒否される
- **SC-004**: マスク表示は値の文字数によらず一貫した表示形式となり、表示内容の不一致は0%である
- **SC-005**: コピー操作からクリップボードへの反映までが100ミリ秒以内に完了する
- **SC-006**: 初期状態（未設定時）では100%の項目がマスク表示される
- **SC-007**: マスク表示の切替操作から画面反映までが200ミリ秒以内に完了する
- **SC-008**: マスク表示の切替状態は、拡張機能を閉じて再度開いても100%保持される
- **SC-009**: グループは最大50個まで作成でき、グループ絞り込み操作から一覧再表示までが300ミリ秒以内に
  完了する
- **SC-010**: グループ削除後、旧所属項目の100%が「未分類」として一覧に表示され、データ欠損は0件である

## Assumptions

- 対応ブラウザはChrome・Edgeの最新版を対象とし、他ブラウザは初期スコープ外とする
- 登録データは端末ローカルに保存し、他端末・他アカウントとの自動同期は初期スコープ外とする
- プライバシーモードは一覧表示のマスクのみを対象とし、PIN/パスワードによる操作ロックは初期スコープ外
  （将来検討のバックログ）とする
- 1項目が所属できるグループは1つまでとし、グループの階層化（親子グループ）は初期スコープ外とする
- 本機能は一般公開（Chrome Web Store / Edgeアドオンストア）を前提とする
