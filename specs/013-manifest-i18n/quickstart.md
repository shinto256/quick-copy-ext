# Quickstart: 拡張機能名・説明の多言語対応

**Feature**: 013-manifest-i18n | **Date**: 2026-09-10

本要件の受入確認手順。自動テストで機械的に検証できる範囲と、ブラウザの表示言語を切り替えて
目視で確認する範囲に分かれる。データ構造の詳細は [data-model.md](./data-model.md)、
守るべき形は [contracts/locale-messages-contract.md](./contracts/locale-messages-contract.md) を参照。

## 前提

- Chrome または Edge がインストールされている
- Node.js と依存パッケージが導入済み（`npm install` 実行済み）
- 表示言語の切り替えのため、ブラウザの言語設定を変更できる権限がある

## Step 1: 自動テストで整合を検証する

```bash
npm test
```

**期待結果**

- 全テストがパスする。既存の209件に加え、`tests/unit/localeMessages.test.js` の分が増える
- `_locales` のキー欠け、manifest 参照との不一致、説明文の132文字超過があればここで失敗する

検証される項目は `data-model.md` の VR-001〜VR-007。対応する受入基準は FR-006〜FR-009 / SC-007〜SC-009。

## Step 2: 拡張機能を読み込む

1. Chrome で `chrome://extensions`（Edge は `edge://extensions`）を開く
2. 「デベロッパーモード」を有効にする
3. 「パッケージ化されていない拡張機能を読み込む」を選択し、リポジトリのルート（`manifest.json` の
   あるディレクトリ）を指定する

**期待結果**（SC-004 / FR-006）

- 読み込みが完了し、拡張機能のカードに警告・エラーが表示されない
- 名称と説明が空欄になっていない

## Step 3: 日本語環境の表示を確認する（User Story 2 / SC-002）

ブラウザの表示言語を日本語にした状態で確認する。

1. Chrome の設定 → 言語 で、日本語を最上位にする
2. ブラウザを再起動する
3. `chrome://extensions` を開き、Quick Copy のカードを見る

**期待結果**

- 名称が `Quick Copy` と表示される
- 説明が `登録した定型文字列をワンクリックでコピーできる拡張機能` と表示される（この変更の前と同一）

## Step 4: 英語環境の表示を確認する（User Story 1 / SC-001）

1. Chrome の設定 → 言語 で、English を最上位にする
2. ブラウザを再起動する
3. `chrome://extensions` を開き、Quick Copy のカードを見る

**期待結果**

- 名称が `Quick Copy` と表示される（SC-007: 日本語環境と同一）
- 説明が `Copy your registered text snippets to the clipboard with a single click.` と表示される
- 説明に日本語の文字が1文字も含まれない

### 地域付きロケールの確認（Edge Case）

表示言語を `English (United Kingdom)` にして再起動し、上記と同じ英語の名称・説明が表示されることを
確認する。`en_GB` が `_locales/en/` で解決されることの確認。

## Step 5: 未対応言語環境の表示を確認する（User Story 3 / SC-003）

日本語・英語以外の言語を3種類以上で確認する。

1. Chrome の設定 → 言語 で、`Deutsch`（ドイツ語）を最上位にする
2. ブラウザを再起動し、`chrome://extensions` を開く
3. `Français`（フランス語）、`中文`（中国語）についても同様に繰り返す

**期待結果**

- いずれの言語環境でも、名称が `Quick Copy`、説明が日本語の
  `登録した定型文字列をワンクリックでコピーできる拡張機能` と表示される（`default_locale: "ja"` への
  フォールバック）
- 名称・説明が空欄になるものが0件である
- 警告・エラーが表示されない

## Step 6: サイドパネル内の言語切替との独立性を確認する（SC-006 / FR-004 / FR-005）

拡張機能の名称・説明の言語と、サイドパネル内の表示言語が互いに影響しないことを確認する。

### 組み合わせ1: ブラウザ日本語 × パネル英語

1. ブラウザの表示言語を日本語にする
2. 拡張機能アイコンをクリックしてサイドパネルを開く
3. その他メニュー（右上の三点リーダー）→ 言語 → `English` を選ぶ

**期待結果**

- サイドパネル内の文字列が英語に切り替わる（再読み込み不要、req-000015 の既存挙動）
- `chrome://extensions` の名称・説明は**日本語のまま**変わらない

### 組み合わせ2: ブラウザ英語 × パネル日本語

1. ブラウザの表示言語を English にして再起動する
2. サイドパネルを開き、その他メニュー → 言語 → `日本語` を選ぶ

**期待結果**

- サイドパネル内の文字列が日本語に切り替わる
- `chrome://extensions` の名称・説明は**英語のまま**変わらない

## Step 7: 既存機能の回帰確認（SC-005 / FR-005）

サイドパネルを開き、次の操作が従来どおり動作することを確認する。

- 項目の登録・編集・削除
- カードのクリックによるコピー
- マスク表示のON/OFF切替
- タブ（グループ）の切替と全グループパネルの開閉
- 項目・グループの並び替え
- 言語切替（日本語 ⇄ English）

**期待結果**

- いずれの操作も本要件の実装前と同じ挙動である
- サイドパネル内にエラー表示が出ない

## 受入基準との対応

| 受入基準 | 確認する Step |
| --- | --- |
| SC-001（英語環境で日本語0文字） | Step 4 |
| SC-002（日本語環境で従来と同一） | Step 3 |
| SC-003（未対応言語3種以上でフォールバック） | Step 5 |
| SC-004（警告・エラー0件） | Step 2, Step 3, Step 4, Step 5 |
| SC-005（既存自動テスト全件パス） | Step 1, Step 7 |
| SC-006（表示言語の組み合わせ2通り） | Step 6 |
| SC-007（名称が両言語で同一） | Step 3, Step 4, Step 1（VR-005） |
| SC-008（説明が132文字以内） | Step 1（VR-004） |
| SC-009（英語の説明が定めた文言と一致） | Step 4, Step 1（VR-007） |

## 確認後の後始末

ブラウザの表示言語を、確認を始める前の設定に戻す。
