# 既存機能の手動確認チェックリスト

**Purpose**: DADS準拠UIデザイン刷新(req-000008)の実装後、既存機能が刷新前と同一に動作することを確認する
**Created**: 2026-09-02
**Feature**: [spec.md](../spec.md) FR-021 / FR-026 / SC-004 / SC-005

既存の自動テストはデータの読み書きと絞り込みのみを対象としており、CSSやHTML属性の変更では失敗しない。本チェックリストが回帰確認の根拠となる。

**実施手順**: [quickstart.md](../quickstart.md) の手順2で拡張機能を読み込んだ状態で、上から順に実施する。

## 項目登録・保存 (req-000001)

- [ ] 項目追加ボタン(✎)を押すと登録フォームが開く
- [ ] 名前と値を入力して保存すると、一覧に追加される
- [ ] 名前を空のまま保存しようとすると、保存されずエラーが示される
- [ ] 名前に51文字以上を入力できない(maxlength=50)
- [ ] 値に2001文字以上を入力できない(maxlength=2000)
- [ ] 値に改行を含む文字列を保存できる
- [ ] キャンセルを押すとフォームが閉じ、項目が追加されない
- [ ] 拡張機能を閉じて再度開くと、登録した項目が残っている

## 一覧表示・コピー (req-000002)

- [ ] 登録済み項目が一覧に表示される
- [ ] 値が既定でマスク表示(伏せ字)されている
- [ ] コピーボタンを押すとクリップボードに値がコピーされる
- [ ] コピー後に成功メッセージが表示され、一定時間後に消える
- [ ] コピーした値を別のフォームに貼り付けると、元の値と一致する
- [ ] **目的の項目をコピーするまでの操作回数が刷新前と同じ**(SC-005)
- [ ] 項目が0件のとき「登録済みの項目はありません。」が表示される
- [ ] 検索欄に文字を入力すると、名前が一致する項目に絞り込まれる
- [ ] 検索で該当がないとき「該当する項目はありません。」が表示される
- [ ] 検索欄を空にすると全項目が再表示される

## マスク表示切替 (req-000003)

- [ ] 「マスクを解除する」をONにすると、値が実際の文字列で表示される
- [ ] OFFに戻すと、値が伏せ字に戻る
- [ ] マスク解除中も、値の長さに関わらず表示が崩れない
- [ ] 長い値(数百文字)がカード内で折り返され、横にはみ出さない

## グループ管理 (req-000004)

- [ ] タブに「すべて」または既定のタブと、作成済みグループが表示される
- [ ] ＋ボタンで新規グループを作成できる
- [ ] タブを切り替えると、そのグループの項目のみが表示される
- [ ] タブのケバブメニューから名称変更ができる
- [ ] タブのケバブメニューから削除ができる
- [ ] グループを削除すると、そのグループの項目が連動して削除される(req-000004 v1.1)
- [ ] 登録フォームのグループ選択で、既存グループを選べる
- [ ] 選択中のタブが色と文字の太さの両方で区別できる
- [ ] 選択中のタブがスクリーンリーダーで「現在の項目」として読み上げられる(`aria-current`)

## 項目並び替え (req-000005)

実機確認(2026-09-02)の結果、ドラッグ&ドロップを廃止し、カード左端の▲▼ボタンによる並び替えに変更した。

- [ ] カード左端に▲▼ボタンが表示される
- [ ] ▲を押すと項目が1つ上へ移動する
- [ ] ▼を押すと項目が1つ下へ移動する
- [ ] 移動が即座に一覧へ反映される
- [ ] 先頭の項目で▲を押しても順序が変わらず、エラーにもならない
- [ ] 末尾の項目で▼を押しても順序が変わらず、エラーにもならない
- [ ] 拡張機能を閉じて再度開いても、並び順が維持されている
- [ ] Tabキーで▲▼ボタンに到達でき、Enterで移動できる(キーボードのみで並び替えが完結する)
- [ ] ケバブメニューが「編集」「削除」の2項目のみになっている(上へ/下へ移動が無い)
- [ ] 検索で絞り込んでいる間は▲▼ボタンが表示されない
- [ ] 選択モード中は▲▼ボタンが表示されない
- [ ] 項目が1件のみのとき、▲▼を押しても順序が変わらない

## テーマ手動切替 (req-000006)

- [ ] その他メニューにテーマの選択肢(自動/ライト/ダーク)が表示される
- [ ] 「ライト」を選ぶとライト配色になる
- [ ] 「ダーク」を選ぶとダーク配色になる
- [ ] 「自動」を選ぶとOSのテーマ設定に追従する
- [ ] 現在選択中のテーマがメニュー上で区別できる
- [ ] 拡張機能を閉じて再度開いても、選択したテーマが維持されている

## 項目一括削除 (req-000007)

- [ ] その他メニューの「選択」で選択モードに入る
- [ ] 選択モード中、各項目にチェックボックスが表示される
- [ ] チェックを入れると「N件選択中」の件数が増える
- [ ] 未選択の状態で削除ボタンが押せない(disabled)
- [ ] 選択した項目をまとめて削除できる
- [ ] キャンセルで選択モードを抜け、項目が削除されない
- [ ] 選択モードを抜けるとチェックボックスが消える

## 表示の刷新に伴う確認

- [ ] ポップアップメニュー(その他メニュー)が背後の一覧より手前に浮いて見える
- [ ] 登録フォームが背後の一覧より手前に浮いて見える
- [ ] 全テキストが14pxで表示され、項目名は太字、項目の値は淡い色で区別できる
- [ ] マスク表示中の伏せ字が、通常テキストと同じ濃さで読める
- [ ] コピー成功メッセージが色だけでなく文言でも成否を伝えている
- [ ] エラーメッセージが色だけでなく文言でも内容を伝えている
- [ ] 項目が多数(20件以上)ある状態で縦スクロールしても、余白と境界線が崩れない
- [ ] 常用漢字外の文字(例: 髙、﨑)を含む項目名でも表示が崩れない
