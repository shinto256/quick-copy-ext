# Data Model: DADS準拠UIデザイン刷新

**Feature**: 004-dads-ui-refresh | **Date**: 2026-09-02

本機能は永続化データを変更しない。`chrome.storage.local` のスキーマ、項目・グループ・設定の構造はすべて現行のまま。ここで定義するのは表示に用いるデザイントークンの構造である。

## エンティティ: デザイントークン

CSSカスタムプロパティとして `sidepanel.css` に定義される、名前と値の対応。テーマごとに値を持つ。

### 属性

| 属性 | 説明 |
|---|---|
| 名前 | `--` で始まるCSSカスタムプロパティ名。種別ごとの接頭辞を持つ |
| 値 | 色は16進表記、寸法はpx、行間は無名数、影はbox-shadow値 |
| テーマ依存 | 色トークンのみテーマごとに値が変わる。書体・余白・角丸・影はテーマ非依存 |
| 出典 | DADSのどのトークンに対応するか(色・角丸・影)、または自前定義か(余白) |

### 種別と接頭辞

| 種別 | 接頭辞 | 個数 | テーマ依存 |
|---|---|---|---|
| 色 | `--color-` | 14 | あり(ライト/ダーク) |
| 書体 | `--font-family-`, `--font-size-`, `--line-height-`, `--letter-spacing-` | 12 | なし |
| 余白 | `--space-` | 6 | なし |
| 角丸 | `--radius-` | 4 | なし |
| 影 | `--elevation-` | 3 | なし |

### 制約

- 色トークンは、ライトテーマとダークテーマの両方で値が定義されていなければならない。
- 前景として用いる色トークンは、組み合わせて表示される背景色トークンに対しコントラスト比4.5:1以上(非テキスト用途は3:1以上)を満たさなければならない。検査対象の組み合わせは [contracts/design-tokens.md](./contracts/design-tokens.md) の「検査ペア」に定義する。
- `--font-size-` の値はいずれも14px以上でなければならない。
- 本文用途の `--line-height-` は1.5以上でなければならない。
- フォーカス表示に用いる色(`#000000` と `#ffd43d`)はDADS指定であり、テーマによる変更を行わない。

### テーマの適用構造

現行の仕組みをそのまま維持する。

```
:root                                   → ライトテーマの全トークン(既定値)
@media (prefers-color-scheme: dark)
  :root:not([data-theme="light"])       → OS設定がダークかつ手動でライト指定していない場合
:root[data-theme="dark"]                → 手動でダーク指定した場合
```

`data-theme` 属性は既存のテーマ手動切替機能([req-000006])が設定する。本機能では値の定義のみを変更し、属性の設定ロジックには手を入れない。

## エンティティ: テーマ設定

既存機能の保存済みデータ。本機能では読み書きしない。

| 属性 | 値 | 保存先 |
|---|---|---|
| テーマ | `auto` / `light` / `dark` | `chrome.storage.local` (既存の設定リポジトリ経由) |

## 状態遷移

デザイントークンに状態遷移はない。テーマ設定の遷移は既存機能の範囲であり、本機能では変更しない。
