# Quickstart: サイドパネル一覧機能拡張の検証手順

## 前提

- Google Chrome（またはEdge）114以降。
- リポジトリを取得済み、`npm install`実行済み。
- 本feature実装後の状態。`chrome://extensions`で拡張機能を読み込み・再読み込み済み。

## 1. 並び替えを確認（User Story 1 / SC-001, SC-002）

1. 同一タブ(グループ)内に3件以上の項目を登録しておく。値の長さが異なる項目(1行のものと
   複数行になるもの)を混ぜておく。
2. カードを掴んで別の位置まで動かし、離す → 移動先のカードが退避して挿入位置が示され、
   離すと一覧の順序が変わることを確認する。値の長さが違ってもずれないこと。
3. カードを押してほとんど動かさずに離す → 並び替えは発生せず、値がコピーされることを確認する。
4. カードにキーボードでフォーカスし、`Alt` + `↑` を押す → 1つ上の位置に移動することを確認する
   (ドラッグ操作の代替手段。上下移動ボタンから置き換わった。`008-item-reorder-unification`)。
5. パネルを閉じて再度開く → 直前の並び順が維持されていることを確認する。
6. 検索欄にキーワードを入力する → カードを掴んでも並び替えが始まらないこと、
   カードにフォーカスして `Alt` + `↑` を押しても並び替わらないことを確認する(FR-004)。
7. 選択モードに入る → カードを掴んでも並び替えが始まらず、コピーも発生しないことを確認する。

**注**: 並び替えの実装は Pointer Events による(`src/sidepanel/dragReorder.js`)。HTML5 の
`draggable` 属性は使わないため、絞り込み中の無効化は属性の有無ではなく操作の受付可否で確認する。
**FR-002 の上下移動ボタン(`▲▼`)は `008-item-reorder-unification` で撤去され、キーボード操作
(カードにフォーカスして `Alt` + 矢印)に置き換わった。** 機構の詳細は
`specs/006-group-navigation/contracts/drag-reorder-contract.md` と
`specs/008-item-reorder-unification/spec.md` を参照。

## 2. テーマ手動固定を確認（User Story 2 / SC-003, SC-004）

1. ヘッダーの「その他メニュー」からテーマ設定を開き、「ダーク」を選択する。
2. OS/Chrome側のテーマ設定をライトに変更する → パネルの表示がダークのまま変わらないことを
   確認する。
3. パネルを閉じて再度開く → 「ダーク」設定が維持されていることを確認する。
4. テーマ設定を「自動」に戻す → OS側の設定に追従する表示に戻ることを確認する。

## 3. 一括削除を確認（User Story 3 / SC-005, SC-006）

1. 複数項目が登録された状態で、ヘッダーの「その他メニュー」から「選択」を選ぶ。
2. 各カードにチェックボックスが表示されることを確認し、2件以上を選択する。
3. 「削除」操作を行う → 確認ダイアログが表示されることを確認する。
4. 承認する → 選択した項目のみが一覧・データから削除され、未選択の項目が残っていることを
   確認する。
5. 再度選択モードに入り、何も削除せず「キャンセル」操作を行う → 選択状態が破棄され通常表示に
   戻ることを確認する。
6. 選択モード中にタブを切り替える、または検索欄に入力する → 選択モードが自動的に終了することを
   確認する。

## 4. 自動テストの実行

```bash
npm run test
```

- 既存テストがすべてパスすること(回帰なし)。
- 新規: `itemRepository.test.js`に追加した`reorderGroup`/`removeMany`のテスト
  （[[contracts/item-repository-additions.md]] 参照）がパスすること。
- 新規: `settingsRepository.test.js`に追加した`setTheme`のテスト
  （[[contracts/settings-repository-additions.md]] 参照）がパスすること。
