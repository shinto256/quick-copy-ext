# Quickstart: 項目並び替え操作の統一の検証手順

## 前提

- Google Chrome（またはEdge）114以降。
- リポジトリを取得済み、`npm install` 実行済み。
- 本feature実装後の状態。`chrome://extensions` で拡張機能を読み込み・再読み込み済み。
- 同一グループ内に**項目を5件以上**登録しておく。値の長さが異なるもの（1行のものと複数行になるもの）と、
  カード幅に収まらない長い名前を持つものを混ぜること。

---

## 1. キーボードで項目を並び替え、コピーする（User Story 1 / SC-003, SC-004, SC-005, SC-007）

**この節はマウスに触らずに実施する**（拡張機能アイコンのクリックのみマウスで行ってよい）。

1. サイドパネルを開き、`Tab` を押してフォーカスを進める → 検索欄・マスク切替・項目追加ボタン・
   その他メニュー・各タブ・パネルを開くボタンを経て、**項目カードにフォーカスが移る**ことを
   確認する（FR-001）。フォーカスリングが表示されること。
2. リングの見た目を、全グループパネルの縦リストの行のリングと見比べる → **同一である**ことを
   確認する（FR-002 / SC-007）。
3. `Tab` を押し続ける → **カード → コピーボタン → 三点リーダー → 次のカード**の順に進むことを
   確認する（FR-010 の前提。各要素が個別にフォーカスできる）。
4. 任意のカードにフォーカスして `Enter` を押す → **値がコピーされ**、コピー完了の表示が出ることを
   確認する（FR-003 / SC-004）。
5. 別のカードにフォーカスして `Space` を押す → 同じく値がコピーされ、**ページがスクロールしない**
   ことを確認する（FR-003）。
6. **一覧の最下部のカード**にフォーカスして `Alt` + `↑` を押す → 1つ上へ移動し、**フォーカスが
   移動したカードに残っている**ことを確認する（FR-004 / FR-007）。
7. `Alt` + `↑` を押し続ける → **先頭まで移動できる**ことを確認する。この間マウスに触らないこと
   （SC-003）。
8. `Alt` + `↓` を押す → 1つ下へ戻ることを確認する（FR-004）。
9. **先頭のカード**にフォーカスして `Alt` + `↑` を押す → 順序が変わらず、エラーも表示されないことを
   確認する（FR-008）。
10. **末尾のカード**にフォーカスして `Alt` + `↓` を押す → 同様に何も起こらないことを確認する（FR-008）。
11. サイドパネルを閉じて開き直す → 並び替えた順序が保持されていることを確認する（FR-006）。
12. **キーが同一であることの確認（SC-005）**: 全グループパネルを開き、縦リストの行で
    `Alt` + `↑` / `↓` を押す → カードと同じキーで並び替えられることを確認する。
13. 検索欄にキーワードを入力してから `Tab` でカードにフォーカスし `Alt` + `↑` を押す →
    **並び替えが行われない**ことを確認する（FR-009 / SC-006）。
14. その他メニューから「選択」で選択モードに入り、`Tab` でカードにフォーカスして `Alt` + `↑` と
    `Enter` を押す → **並び替えもコピーも行われない**ことを確認する（FR-009 / SC-006）。
15. コピーボタンにフォーカスして `Alt` + `↑` を押す → 並び替えが行われないことを確認する（FR-010）。
    三点リーダー、選択モード中のチェックボックスでも同様に確認する。

---

## 2. 上下移動ボタンの撤去（User Story 2 / SC-001）

1. 項目一覧の各カードを確認する → **`▲▼` の上下移動ボタンが表示されていない**ことを確認する
   （FR-011 / SC-001）。
2. カードに残っている操作要素を確認する → **コピーボタンと三点リーダーのみ**であることを確認する
   （FR-012）。
3. 選択モードに入る → チェックボックスが加わり、それ以外の操作要素は増えていないことを確認する（FR-012）。
4. **カード幅に収まらない長い名前を持つ項目**のカードを確認する → 上下移動ボタンがあった頃より
   名前と値の表示幅が広く、省略される位置が後ろにずれていることを確認する（FR-013）。
5. 三点リーダーのメニューを開く → 「編集」「削除」のみで、「上へ移動」「下へ移動」がないことを
   確認する（FR-011。spec 003 FR-002 の置き換え）。

## 3. 既存のポインタ操作の回帰確認（SC-008）

**この節はマウスを使って実施する。** カードを `tabindex="0"` にした変更とボタン撤去が、
既存のドラッグ判定を壊していないことが検証対象。

1. カードを掴んで別の位置まで動かし、離す → 移動先のカードが退避して挿入位置が示され、
   離すと並び替えが確定する（FR-014）。
2. 値の長さが異なるカード（1行のものと複数行になるもの）を混ぜた状態で並び替える →
   退避と吸着がずれないことを確認する。
3. カードを押してほとんど動かさずに離す → **並び替えではなく値がコピーされる**ことを確認する
   （5px閾値の判定。FR-014）。
4. カードを押して5px以上動かしてから離す → コピーは発生せず並び替えが確定することを確認する（FR-014）。
5. コピーボタン・三点リーダーをポインタで押す → 並び替えもカードのコピーも発生せず、
   それぞれの操作だけが起きることを確認する。
6. 一覧が画面に収まらない状態で、カードを掴んだままウィンドウの上端・下端へ寄せる →
   サイドパネル全体がスクロールすることを確認する。
7. 検索絞り込み中にカードを掴む → 並び替えが始まらないが、押して離せばコピーはできることを確認する。
8. 選択モード中にカードを掴む → 並び替えが始まらず、コピーも発生しないことを確認する。

---

## 4. 既存機能の回帰確認

1. 項目の登録・編集・削除がこれまでどおり行えること。
2. マスク表示の切替が動作すること。
3. 項目名検索で絞り込めること。
4. 選択モードによる一括削除・一括グループ変更が動作すること。
5. グループ側の機能（全グループパネルの一覧・絞り込み・ドラッグ並び替え・キーボード並び替え・
   名称変更・削除・追加、タブ切替）がすべて動作すること。
6. オーバーレイのフォーカストラップと `Escape` での復帰が動作すること。
7. テーマの自動追従とライト/ダークの手動固定が動作すること。

---

## 5. 自動テストの実行

```bash
npm test
```

- 既存テストがすべてパスすること（回帰なし）。本featureは storage層を変更しない。
- 追加: `tests/unit/listReorder.test.js` の `reorderOffsetFromKey` / `isActivationKey` のテスト
  （[contracts/reorder-keys-contract.md](./contracts/reorder-keys-contract.md) 参照）がパスすること。

カードのキーイベント処理とフォーカス復帰はDOM操作が中心のため、既存specと同方針でユニットテスト
対象外とし、上記1〜4の手動検証で担保する。
