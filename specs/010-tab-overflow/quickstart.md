# Quickstart: タブバーの横スクロール廃止と幅追従表示の検証手順

## 前提

- Google Chrome（またはEdge）114以降。
- リポジトリを取得済み、`npm install` 実行済み。
- 本feature実装後の状態。`chrome://extensions` で拡張機能を読み込み・再読み込み済み。
- **グループを10個以上**登録しておく。名前の長さがまちまちになるようにする（2文字のものと
  20文字のものを混ぜる）。
- サイドパネルの幅を変える操作を使う。サイドパネルとページの境界をドラッグして幅を変えられる。

---

## 1. 横スクロールバーが出ない（User Story 1 / SC-001, SC-002, SC-008）

1. サイドパネルを開いてタブバーを確認する → **横スクロールバーが表示されていない**ことを
   確認する（FR-001 / SC-001）。
2. タブバーの右端を確認する → **タブがタブバーからはみ出していない**ことを確認する
   （FR-003 / SC-002）。表示されているタブは全体が見えていること。
3. タブバー末尾の全グループパネルを開くボタンを確認する → **表示されている**ことを確認する
   （FR-006 / SC-005）。
4. そのボタンに併記されている数を確認する → **隠れているタブも含めた全タブ数**（未分類 +
   グループ数）であることを確認する（FR-007）。表示されているタブの数ではないこと。
5. そのボタンから全グループパネルを開く → **タブバーに表示されていなかったグループも縦リストに
   並んでいる**ことを確認する（FR-014 / SC-007）。そこから切り替えられること。
6. サイドパネルの幅を十分に広げて**全タブが収まる状態**にする → すべてのタブが表示され、
   隠れているタブが0件であることを確認する（SC-008）。横スクロールバーも出ないこと。
7. `Tab` でフォーカスを進める → **隠れているタブにフォーカスが当たらない**ことを確認する
   （FR-013 / SC-006）。表示されているタブとボタンだけを通ること。

---

## 2. 幅を変えると表示が追従する（User Story 2 / SC-003）

1. タブが隠れている状態から、サイドパネルの幅を**少しずつ広げる** → **収まるようになったタブが
   順に表示される**ことを確認する（FR-009 / FR-010 / SC-003）。
2. 幅を**少しずつ狭める** → 収まらなくなったタブが順に隠れることを確認する（FR-011）。
   **この間、横スクロールバーが一時的にも現れない**こと（FR-001）。
3. 幅を変えている最中（ドラッグ中）にタブバーを見る → はみ出したタブが一瞬でも現れないことを
   確認する（FR-003）。
4. 全グループパネルからグループを**追加**する → タブバーの表示が再計算され、収まる範囲で
   新しいタブが表示されることを確認する（FR-012）。
5. グループを**削除**する → 空いた幅に収まるタブが表示されることを確認する（FR-012）。
6. 全グループパネルでタブの**並び順を変える** → 新しい並び順の先頭から詰めて表示されることを
   確認する（FR-004 / FR-012）。
7. グループの**名称を長い名前に変更**する → タブの幅が変わり、表示するタブが再計算されることを
   確認する（FR-012）。短い名前に戻すと表示されるタブが増えることも確認する。
8. サイドパネルを閉じて開き直す → 現在の幅に応じた表示になっていることを確認する。

---

## 3. いま見ているグループが分かる（User Story 3 / SC-004）

**本specで最も壊れやすい部分。**

1. タブが隠れる幅にしておく。
2. 全グループパネルを開き、**タブバーに表示されていない（並び順の後ろにある）グループ**を選んで
   切り替える。
3. タブバーを確認する → **そのタブが選択中として表示されている**ことを確認する
   （FR-005 / SC-004）。
4. そのとき **横スクロールバーが出ておらず、はみ出しているタブもない**ことを確認する（FR-001 / FR-003）。
   選択中のタブを表示するために他のタブが隠れていること。
5. 並び順の**先頭のグループ**に切り替える → 選択中のタブがそのまま収まる位置なので、
   **他のタブが余分に隠れていない**ことを確認する（FR-008）。手順3のときより表示されているタブが
   多いこと。
6. 選択中のタブが表示されている状態から、サイドパネルの幅を**限界まで狭める** →
   **選択中のタブは最後まで隠れない**ことを確認する（FR-005）。
7. タブが1つも収まらないほど狭い状態にする → **選択中のタブと末尾のボタンのみ**が表示され、
   選択中のタブの名前が末尾省略で表示されることを確認する（FR-005 / FR-006）。
8. 手順7の状態から幅を広げる → 他のタブが順に表示されることを確認する。

---

## 4. 既存機能の回帰確認

1. タブを押すとグループが切り替わること。表示されているタブすべてで確認する。
2. 選択中のタブが選択中の見た目（背景色・太字）になっていること。
3. タブ名が長い場合に末尾省略で表示され、マウスを乗せると全文がツールチップで出ること
   （`006-group-navigation` FR-024）。
4. 全グループパネルの一覧・絞り込み・ドラッグ並び替え・キーボード並び替え（`Alt` + 矢印）・
   名称変更・削除・追加がすべて動作すること。
5. 全グループパネルのフォーカストラップと `Escape` での復帰が動作すること。
6. 拡張機能を開いたとき、並び順の先頭のタブが選択された状態で開くこと。
7. 項目一覧・項目カードのドラッグ並び替え（掴み手から）・キーボード並び替え・タップでのコピーが
   動作すること。
8. 項目の登録・編集・削除、マスク表示の切替、項目名検索、選択モードによる一括削除・
   一括グループ変更が動作すること。
9. テーマの自動追従とライト/ダークの手動固定が動作すること。

---

## 5. 自動テストの実行

```bash
npm test
```

- 既存テストがすべてパスすること（回帰なし）。本featureは storage層を変更しない。
- 新規: `tests/unit/tabOverflow.test.js` の `visibleTabIndexes` のテスト
  （[contracts/tab-overflow-contract.md](./contracts/tab-overflow-contract.md) 参照）がパスすること。
  **全部収まる / 一部だけ収まる / 1つも収まらない、選択中のタブが収まる位置にある / ない、
  の各条件を網羅していること。**

DOMの計測・`hidden` の付け外し・`ResizeObserver` の配線はDOM操作が中心のため、既存specと
同方針でユニットテスト対象外とし、上記1〜4の手動検証で担保する。
