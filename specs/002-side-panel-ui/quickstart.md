# Quickstart: サイドパネルUI刷新の検証手順

## 前提

- Google Chrome（またはEdge）114以降。
- リポジトリを取得済み、`npm install` 実行済み（vitest等の開発依存関係）。
- 本feature実装後の状態（`manifest.json` が `side_panel` / `background` を持ち、
  `src/sidepanel/` が存在する状態）。

## 1. 拡張機能を読み込む

1. `chrome://extensions` を開き、デベロッパーモードを有効化する。
2. 「パッケージ化されていない拡張機能を読み込む」からリポジトリのルートディレクトリを選択する。

## 2. サイドパネルの常駐表示を確認（User Story 1 / SC-001, SC-002）

1. 拡張機能アイコンをクリックする → ブラウザ右側にパネルが開くことを確認する。
2. 別のタブに切り替える → パネルが閉じずに表示され続けることを確認する。
3. 登録済み項目のコピー操作を行う → クリップボードに値が入り、成功フィードバックが出ることを
   `navigator.clipboard` の貼り付け確認、または画面上の通知で確認する。

## 3. タブ（グループ）切替を確認（User Story 2 / SC-005）

1. 複数グループ・複数項目を事前に登録しておく（手順4で作成可）。
2. パネル上部のタブを切り替え、選択中グループの項目のみが一覧表示されることを確認する。
3. タブ末尾の「＋」から新規グループを作成し、タブが増えることを確認する。

## 4. 画面遷移なしの登録・編集・削除・グループ管理を確認（User Story 3 / SC-003, SC-004）

1. ヘッダーの項目追加操作を行う → パネル内に入力UIが表示され、URLやページ遷移が発生しない
   ことを確認する（開発者ツールのNetwork/Navigationログで別ドキュメント読み込みが無いことを
   確認してもよい）。
2. 名前・値・所属グループを入力し保存する → 入力UIが閉じ、該当タブの一覧に即時反映される
   ことを確認する。
3. カードの編集操作から既存項目を変更し保存する → 画面遷移なしに一覧へ反映されることを
   確認する。
4. カードの削除操作を行う → 確認の上、画面遷移なしに一覧から消えることを確認する。
5. グループの名称変更・削除を行う → 画面遷移なしにタブへ反映され、削除時は所属項目が
   「未分類」タブへ移動することを確認する。

## 5. 検索とタブ切替リセットを確認（User Story 4）

1. 検索欄にキーワードを入力し、名前一致する項目のみに絞り込まれることを確認する。
2. 別タブに切り替え、検索欄が自動的にクリアされ絞り込みが解除されていることを確認する
   （Clarifications参照）。

## 6. マスク切替の一操作性を確認（req-000003 / FR-012）

1. ヘッダーのマスク切替トグルを1回操作する → メニュー等を開く追加操作なしに、選択中タブの
   全項目の値表示がマスク⇔平文に切り替わることを確認する。
2. パネルを閉じて再度開き、直前の表示モードが保持されていることを確認する。

## 7. 自動テストの実行

```bash
npm run test
```

- 既存: `itemRepository.test.js` / `groupRepository.test.js` / `settingsRepository.test.js` /
  `maskDisplay.test.js` が引き続きパスすること（storage層は無変更）。
- 新規: `itemFilter.test.js`（[[contracts/item-filter-contract.md]] 参照）がパスすること。
