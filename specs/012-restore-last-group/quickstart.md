# Quickstart: グループ選択状態の復元の検証手順

## 前提

- Google Chrome（またはEdge）114以降。
- リポジトリを取得済み、`npm install` 実行済み。
- 本feature実装後の状態。`chrome://extensions` で拡張機能を読み込み・再読み込み済み。
- 検証用データとして**グループを3件以上**登録済み（並べ替え順の先頭・中間・末尾を区別できる状態）。

---

## 1. 最後に選択していたグループの復元（User Story 1 / SC-001）

1. サイドパネルを開く → 並べ替え順の先頭グループが選択されていることを確認する（変更前の既定挙動）。
2. 先頭以外の任意のグループ（例: 2番目）を選択する。
3. サイドパネルを閉じる（拡張機能アイコンを再度押す、またはウィンドウを閉じる）。
4. サイドパネルを再度開く → 手順2で選択したグループが選択状態で表示されることを確認する（FR-001,
   FR-002）。

## 2. 並べ替え変更後も選択記憶を優先（User Story 2 / SC-002）

1. グループAが並べ替え順で先頭でない状態にする。
2. グループAを選択する。
3. 全グループパネルでグループAを含む並べ替え順を変更する（グループAの相対位置を変えず、他グループの
   順序だけ変えても、グループAを先頭に移動させても、いずれの操作でもよい）。
4. サイドパネルを閉じて再度開く → 並べ替え後の先頭グループではなく、グループAが選択状態で表示される
   ことを確認する（FR-003）。

## 3. 選択グループ削除時のフォールバック（User Story 3 / SC-003）

1. グループBを選択する。
2. 全グループパネルからグループBを削除する。
3. サイドパネルを閉じて再度開く → エラー表示や空白表示にならず、並べ替え順の先頭グループが選択状態で
   表示されることを確認する（FR-004）。

## 4. 未分類タブの選択記憶（Clarification 2026-09-10）

1. 「未分類」タブを選択する。
2. サイドパネルを閉じて再度開く → 「未分類」タブが選択状態で表示されることを確認する（FR-002、
   未分類タブを含む）。

## 5. 初回起動時のフォールバック（Edge Case / FR-005）

1. `chrome://extensions` の「Service Worker」コンソール（または拡張機能のリロード）から
   `chrome.storage.local` の `settings` キーを削除、または初めて拡張機能をインストールした状態を再現
   する。
2. サイドパネルを開く → 並べ替え順の先頭グループが選択状態で表示されることを確認する。

## 検証対象外（本featureの変更なし）

- 項目登録・編集・削除・コピー操作
- マスク表示のON/OFF
- グループの追加・名称変更・並べ替え操作そのもの
- 選択モード（一括削除・一括グループ変更）
