# Feature Specification: グループ選択状態の復元

**Feature Branch**: `feature/req-000016`

**Created**: 2026-09-10

**Status**: Draft

**Input**: User description: "req-000016: グループ選択状態を最後に開いたグループで復元する。Quick Copy popupを閉じて再度開いたとき、現状は並べ替え順先頭のグループが常に選択されるが、これを最後に選択していたグループを記憶し復元する仕様に変更する。並べ替え順変更後も選択記憶を優先。選択グループ削除時は先頭へフォールバック。初回起動時は先頭グループ選択。"

## Clarifications

### Session 2026-09-10

- Q: 選択記憶・復元の対象に「未分類」タブ（グループ未設定項目をまとめる特殊タブ）も含めるべきか？ → A: 含める。未分類タブ選択中に閉じて再度開いても、未分類タブが復元される

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 最後に選択していたグループの復元 (Priority: P1)

複数グループで定型文字列を管理しているユーザーが、あるグループを選択した状態でQuick Copyを閉じ、再度開いたときに、閉じる直前と同じグループが選択された状態で表示される。

**Why this priority**: 本要件の中核価値。毎回先頭グループに戻ってしまう不便さを解消し、作業中のグループへ即座にアクセスできるようにする、最も優先度の高い振る舞い。

**Independent Test**: 先頭以外の任意のグループを選択した状態でサイドパネルを閉じ、再度開いて選択グループが維持されていることを確認するだけで独立して検証できる。

**Acceptance Scenarios**:

1. **Given** グループが複数登録されており、ユーザーが並べ替え順で2番目以降のグループを選択している, **When** Quick Copyを閉じて再度開く, **Then** 直前に選択していたグループが選択状態で表示される
2. **Given** ユーザーが先頭グループを選択している, **When** Quick Copyを閉じて再度開く, **Then** 引き続き先頭グループが選択状態で表示される

---

### User Story 2 - 並べ替え変更後も選択記憶を優先 (Priority: P2)

ユーザーがグループの並べ替え順を変更した後にQuick Copyを閉じて再度開いても、並べ替え後の先頭グループではなく、直前に選択していたグループ自体が選択される。

**Why this priority**: 並べ替え順と選択状態の記憶が競合しうる代表的なケース。並べ替え操作によって選択記憶がリセットされないことを保証する必要がある。

**Independent Test**: グループを選択→並べ替え順を変更（選択グループが先頭でなくなる操作）→Quick Copyを閉じて再度開き、並べ替え後の先頭ではなく選択していたグループが表示されることを確認する。

**Acceptance Scenarios**:

1. **Given** グループAを選択した状態で、グループAが先頭でない順序に並べ替える, **When** Quick Copyを閉じて再度開く, **Then** 並べ替え後の先頭グループではなくグループAが選択状態で表示される

---

### User Story 3 - 選択グループ削除時のフォールバック (Priority: P3)

ユーザーが選択していたグループを削除した状態でQuick Copyを閉じ、再度開いたときに、存在しないグループを選択しようとしてエラーにならず、先頭グループが選択された状態で表示される。

**Why this priority**: 発生頻度は低いが、記憶した選択グループが存在しなくなるケースへの安全な代替動作を保証する必要がある。

**Independent Test**: グループBを選択した状態でグループBを削除し、Quick Copyを閉じて再度開き、先頭グループが選択された状態で表示されエラーが発生しないことを確認する。

**Acceptance Scenarios**:

1. **Given** グループBを選択した状態でグループBが削除される, **When** Quick Copyを閉じて再度開く, **Then** 先頭グループが選択状態で表示される

---

### Edge Cases

- グループが1件も登録されていない場合、選択状態の復元は適用されない（グループ一覧自体が空の通常表示となる）
- グループが1件のみ登録されている場合、常にそのグループが選択される
- 初回起動（選択履歴が一度も記録されていない）時は、並べ替え順の先頭グループが選択される
- 選択記憶を持たない旧バージョンからのアップグレード直後も、初回起動と同様に先頭グループが選択される

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: システムは、ユーザーがグループを選択するたびに、その選択状態を記憶しなければならない
- **FR-002**: システムは、Quick Copyを開く際、記憶している最後に選択されたグループ（未分類タブを含む）が現存する場合、そのグループを選択状態で表示しなければならない
- **FR-003**: システムは、記憶している選択グループの並べ替え順上の位置に関わらず、当該グループを選択状態で復元しなければならない
- **FR-004**: システムは、記憶している選択グループが削除等により存在しない場合、並べ替え順で先頭のグループを選択状態で表示しなければならない
- **FR-005**: システムは、選択グループの記憶が一度も存在しない場合（初回起動時等）、並べ替え順で先頭のグループを選択状態で表示しなければならない

### Key Entities

- **選択状態（最後に選択されたグループの記憶）**: どのグループ（未分類タブを含む）が直近に選択されていたかを示す情報。グループの識別情報を保持し、グループ一覧の並べ替え順とは独立して管理される

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 先頭以外のグループを選択した状態でQuick Copyを閉じて再度開いた場合、100%のケースで直前に選択していたグループが選択状態で表示される
- **SC-002**: グループの並べ替え順を変更した後も、選択していたグループが先頭グループにすり替わることなく復元される
- **SC-003**: 選択していたグループが削除された場合でも、Quick Copyがエラー表示や空白表示になることなく先頭グループへ正しくフォールバックする

## Assumptions

- 選択状態の記憶は、当該ブラウザ・端末上でのみ保持されればよく、他端末との同期は対象外とする（既存のローカル保存方針に準拠）
- 「グループを選択する」とは、Quick Copyサイドパネル内でユーザーが明示的にグループ（未分類タブを含む）を切り替える操作を指す
- プライバシーモードのON/OFFなど他の表示設定とは独立した機能であり、相互に影響しない
