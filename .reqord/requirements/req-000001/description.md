# 項目登録・保存機能

## 概要

ユーザーが「コピーしたい内容(値)」とその内容がひと目でわかる「名前(ラベル)」を入力し、
拡張機能に保存できる機能。例: 名前="住所"、値="東京都..."。

## EARS形式要件

When ユーザーが拡張機能の登録フォームで名前と値を入力し保存を実行したとき,
if 名前・値がともにバリデーション条件を満たしている場合,
the system shall 入力された項目(名前・値のペア)を端末ローカルのストレージに保存する,
保存完了後、一覧画面に新しい項目を即時反映する。

## 詳細要件

- 1項目は「名前(ラベル)」「値(コピー対象文字列)」の組で構成する。
- 名前は1〜50文字、値は1〜2000文字の範囲で入力を受け付ける。
- 名前・値のいずれかが空、または文字数上限を超える場合は保存せずエラーを表示する。
- 登録済み項目は編集・削除ができる（詳細は本要件のスコープ内で実装、UIは一覧画面に統合）。

## ユースケース

1. ユーザーが「新規登録」操作を行い、名前と値の入力欄を表示する。
2. 名前欄に「住所」、値欄に「東京都...」を入力し、保存操作を行う。
3. バリデーションを通過した項目が一覧に追加され、保存完了が画面に表示される。

## 技術的制約

- 保存先は chrome.storage.local（[[technical.yaml]] の方針に準拠）。
- 登録可能件数は最大500件までとする。

## エッジケース

- 名前または値が未入力のまま保存操作された場合、0件も保存されずエラーメッセージを表示する。
- 登録件数が上限(500件)に達している状態で追加登録しようとした場合、保存を拒否し上限到達を通知する。
- 同名の名前(ラベル)が複数登録された場合も許容する(値の区別で運用は利用者に委ねる)。

## 成功基準

- 保存操作から一覧への反映までが1秒以内に完了する。
- 名前(1〜50文字)・値(1〜2000文字)の文字数バリデーションについて、範囲内入力は100%保存を許可し、範囲外入力は100%エラーとする。
- 登録上限は500件で、501件目の保存操作は100%拒否される。
- 名前または値が未入力の保存操作は100%エラーとなり、保存件数が0件のまま変化しない。
