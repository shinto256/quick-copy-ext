# 選択項目グループ一括変更機能

## 概要

サイドパネルの一覧から複数の項目を選択している際に、選択したすべての項目のグループをまとめて変更できる機能。あわせて、選択モード中は各カードの三点リーダー(個別メニュー)およびコピーボタンを操作不可にし、選択操作以外の誤操作を防ぐ。

## EARS形式要件

When ユーザーが一覧内で複数項目を選択し、一括グループ変更操作を行ったとき,
if 変更先グループが選択された場合,
the system shall 選択されたすべての項目のグループを指定グループに変更する,
変更完了後、一覧・グループ絞り込み表示に変更を即時反映する。

While 選択モードが有効な間,
the system shall 各カードの三点リーダー(個別メニュー)およびコピーボタンを操作不可にする,
選択操作中に個別のコピー・削除等の誤操作が発生しないようにする。

## 詳細要件

- 選択は既存の一括削除[[req-000007]]と同じ選択UI(各カードのチェックボックス)を利用する。
- 選択モードが有効な間、対象カードの三点リーダーメニューおよびコピーボタンは無効化(押下不可)する。
- 「選択項目のグループを変更」操作で、既存のグループ一覧([[req-000004]])から変更先グループを選択し、選択中の全項目のグループを一括で変更する。
- 選択中に一覧が再描画される操作(タブ切替・検索)が発生した場合、選択状態はリセットする([[req-000007]]と同様)。

## ユースケース

1. ユーザーが一覧内の複数カードのチェックボックスを選択する。
2. 選択モード中は各カードの三点リーダー・コピーボタンが無効化され、押下できない。
3. 「選択項目のグループを変更」操作を行い、変更先グループを選択する。
4. 選択された全項目のグループが一括で変更され、一覧・グループ絞り込み表示に即時反映される。

## 技術的制約

- グループ変更処理は既存の`ItemRepository`のグループ更新APIを選択件数分呼び出す形で実現する想定（storage層のAPI変更は不要）。
- 選択状態の管理・リセットロジックは既存の一括削除機能([[req-000007]])の実装を再利用する。

## エッジケース

- 選択件数が0件の状態で一括グループ変更操作をしても、エラーにはならず何も変更しない。
- 選択中に一覧が再描画される操作(タブ切替・検索)が発生した場合、選択状態はリセットする。

## 成功基準

- 選択モード中は、対象カードの三点リーダーおよびコピーボタンが100%操作不可になる。
- 一括グループ変更操作から一覧表示への反映までが1秒以内に完了する。
- 選択した項目の100%のグループが変更され、未選択項目のグループ変更は0件である。
- 選択件数が0件の状態で一括グループ変更操作をしてもエラーにならず、変更は発生しない。
