# タブバーの横スクロール廃止と幅追従表示

## 概要

グループのタブバーは、タブが幅に収まらないと横スクロールになる。狭いサイドパネルではスクロールバーが常に見える状態になり、限られた縦方向の領域をスクロールバーが占め、見た目も落ち着かない。またタブを横スクロールして探す操作は、全グループパネル（[[req-000010]]）で一覧と絞り込みができるようになった今では役目が薄い。

タブバーの横スクロールを廃止し、**幅に収まらないタブは表示しない**。隠れたタブは全グループパネルから一覧・絞り込みで到達できるため、アクセス手段は失われない。

サイドパネルは利用者が幅を変えられる。幅を広げて余白ができたら、収まるようになったタブを表示する。幅を狭めたら、収まらなくなったタブを隠す。

## EARS形式要件

While グループのタブバーが表示されている間,
the system shall タブバーに横スクロールを発生させない,
スクロールバーが領域を占めることと、横スクロールで探す操作をなくす。

When タブの合計幅がタブバーの幅を超えたとき,
the system shall 収まらないタブを表示しない,
表示するタブの範囲を、スクロールなしで一度に見える範囲に限定する。

When 利用者がサイドパネルの幅を変えたとき,
the system shall 表示するタブを新しい幅に合わせて再計算する,
幅を広げて余白ができれば収まるタブを表示し、狭めれば収まらないタブを隠す。

While タブが隠れている間,
the system shall 選択中のタブを必ず表示する,
いまどのグループを見ているのかが分からなくなることを防ぐ。

## 詳細要件

- タブバーの横スクロールを廃止する。スクロールバーを表示しない。
- タブの表示は並び順の先頭から詰めていき、幅に収まらないタブは表示しない。並び順は利用者が決めるため（[[req-000010]]）、よく使うタブを先頭に置けば表示される。
- **選択中のタブは、並び順の位置にかかわらず必ず表示する。** 収まらない位置にある場合は、他のタブを隠して選択中のタブの場所を作る。
- 全グループパネルを開くボタンは常に表示する。タブが1つも収まらない場合でも、このボタンと選択中のタブは表示する。
- ボタンに併記するタブの総数は、隠れているタブも含めた全タブ数のままとする。隠れているタブがあることが数から分かる。
- サイドパネルの幅が変わったら、表示するタブを再計算する。幅を広げて余白ができた場合は、収まるようになったタブを表示する。
- 隠れているタブは、キーボードのフォーカス移動の対象にもしない。見えないタブにフォーカスが当たることを防ぐ。
- 隠れているタブへは全グループパネル（[[req-000010]]）から到達する。この経路は変更しない。

## ユースケース

1. 利用者がグループを10個作る。タブバーには幅に収まる3個と、全グループパネルを開くボタンだけが表示される。横スクロールバーは出ない。
2. 利用者がサイドパネルの幅を広げる。収まるようになったタブが追加で表示される。
3. 利用者が全グループパネルから、タブバーに表示されていないグループへ切り替える。そのタブが選択中として表示され、代わりに別のタブが隠れる。
4. 利用者がよく使うグループを並び順の先頭へ移動する。以降そのタブは常にタブバーに表示される。

## 技術的制約

- 表示するタブの判定は、タブの実際の幅を測って行う必要がある。名前の長さによってタブの幅は変わるため、固定の個数では決められない。
- サイドパネルの幅の変化を検知する仕組みが必要になる。
- 表示の再計算がタブの描画のたびに走るため、計測の回数を抑える。

## エッジケース

- タブが1つも幅に収まらない場合、選択中のタブと全グループパネルを開くボタンのみを表示する。選択中のタブは幅に収まらなくても表示する（名前は末尾省略で表示される）。
- タブが全部収まる場合は、すべてのタブを表示する。何も隠れない。
- 選択中のタブが並び順の先頭に近く、そのまま収まる場合は、他のタブを余分に隠さない。
- 幅を狭めていく途中で選択中のタブだけが残る状態になっても、選択中のタブは隠さない。
- グループの追加・削除・並び替え・名称変更のあとも、表示するタブを再計算する。

## 成功基準

- タブバーに横スクロールバーが表示される事象が0件である。
- タブが幅に収まらない状態で、タブバーからはみ出して表示されるタブが0件である。
- サイドパネルの幅を広げて余白ができた場合、収まるようになったタブが表示される。
- 選択中のタブがタブバーに表示されない事象が0件である。
- 全グループパネルを開くボタンが表示されない事象が0件である。
- 隠れているタブにキーボードのフォーカスが当たる事象が0件である。
- 隠れているタブへ全グループパネルから到達できる割合が100%である。
