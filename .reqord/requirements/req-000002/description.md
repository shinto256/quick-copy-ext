# 一覧表示・コピー機能(デフォルトマスク表示)

## 概要

登録済み項目を一覧表示し、コピー操作で値をクリップボードにコピーする機能。
名前は常に平文表示、値はデフォルトでマスク(●●)表示とする。

## EARS形式要件

When ユーザーが拡張機能のポップアップを開いたとき,
if マスク非表示モード([[req-000003]])がOFF(デフォルト)の場合,
the system shall 登録済み項目の名前を平文表示し、値を●でマスクして一覧表示する,
コピー操作(ボタン押下)により、表示状態に関わらず値の原文をクリップボードへコピーする。

## 詳細要件

- 一覧は [[req-000001]] で保存された全項目を表示する。
- 名前は常に平文表示（マスク対象外）。
- 値はマスクモード時、文字数によらず固定8文字の「●」で統一表示する（値の文字数を推測させない）。
- 各項目にコピー操作ボタンを設け、押下でその項目の値(原文)をクリップボードにコピーする。
- コピー成功時は画面上部にトースト通知を表示する。

## ユースケース

1. ユーザーが拡張機能アイコンをクリックしポップアップを開く。
2. 一覧に登録済み項目が「名前 + マスク値」の形式で表示される。
3. コピーしたい項目のコピーボタンを押すと、値の原文がクリップボードにコピーされる。
4. コピー成功のフィードバックが表示される。

## 技術的制約

- クリップボード書き込みは Clipboard API（`navigator.clipboard.writeText`）を使用する。
- 表示ロジックは popup モジュール（[[structure.yaml]]参照）に実装する。

## エッジケース

- 登録項目が0件の場合、一覧に「未登録」を示す空状態を表示する。
- クリップボードAPIが利用できない/権限がない場合、コピー失敗を明示的に通知する。
- 値が空文字の項目は登録不可のため（[[req-000001]]）、一覧上で値が空になるケースは発生しない。

## 成功基準

- マスク表示は値の文字数によらず「●」8文字で統一表示する（不一致率0%）。
- コピー操作からクリップボード反映までが100ms以内に完了する。
- 初期状態（マスク非表示モード未設定時）で100%の項目がマスク表示される。
- コピー成功時、1秒以内に成功フィードバックが表示される。
