# グループ選択状態を最後に開いたグループで復元する

## ユーザーストーリー

As a 複数グループで定型文字列を管理しているユーザー,
I want Quick Copyを再度開いたときに最後に選択していたグループが選択された状態で表示されてほしい,
So that 並べ替え順の先頭グループに毎回切り替わる手間なく、作業中のグループにすぐアクセスできる。

## 詳細

現状、Quick Copyを閉じて再度開くと、グループの並べ替え順で先頭に位置するグループが常に選択された状態で表示される。ユーザーが直前に別のグループを選択していても、その選択状態は保持されず先頭グループにリセットされてしまう。

本要件では、直前にユーザーが選択していたグループを記憶し、次回起動時にそのグループを選択状態で開くようにする。並べ替え順の変更によって選択グループの相対位置が変わっても、記憶している選択グループ自体を優先して復元する。選択していたグループが削除されていた場合は、先頭グループへフォールバックする。

## 成功基準

- Quick Copyを閉じて再度開いたとき、閉じる直前に選択していたグループが選択状態で表示される
- グループ並べ替え順変更後も、復元は「最後に選択したグループ」を優先する（先頭固定にならない）
- 選択していたグループが削除済みの場合、先頭グループへフォールバックする
- 初回起動（選択履歴なし）時は先頭グループが選択される
