# 項目一括削除機能

## 概要

サイドパネルの一覧から複数の項目を選択し、まとめて削除できる機能。

## EARS形式要件

When ユーザーが一覧内で複数項目を選択し、一括削除操作を行ったとき,
if 削除確認操作(確認ダイアログ等)で削除が承認された場合,
the system shall 選択されたすべての項目を一覧および永続化データから削除する,
削除完了後、一覧に変更を即時反映する。

## 詳細要件

- 選択は現在表示中(選択中タブ・検索絞り込み後)の項目に対して行う(各カードにチェックボックス等の選択UIを設ける)。
- 一括削除は既存の単体削除[[req-000001]]と同じ確認フロー(誤操作防止の確認ダイアログ)を経る。
- 削除確定後は取り消し不可とする(既存の単体削除の仕様[[req-000001]]と同様)。

## ユースケース

1. ユーザーが一覧内の複数カードのチェックボックスを選択する。
2. 「選択項目を削除」操作を行う。
3. 確認ダイアログで削除を承認すると、選択された全項目が一覧・ストレージから削除される。

## 技術的制約

- 削除処理は既存の`ItemRepository.remove()`を選択件数分呼び出す形で実現する想定（storage層のAPI変更は不要）。

## エッジケース

- 選択件数が0件の状態で一括削除操作をしても、エラーにはならず何も削除されない。
- 選択中に一覧が再描画される操作(タブ切替・検索)が発生した場合、選択状態はリセットする。

## 成功基準

- 一括削除操作から一覧への反映までが1秒以内に完了する。
- 選択した項目の100%が削除され、未選択項目は0件も削除されない。
