# 項目並び替え操作の統一

## 概要

項目一覧のカードとグループの縦リストは、どちらも並び替えができるが操作手段が揃っていない。カードにはドラッグ操作と各カード左端の上下移動ボタン（`▲▼`）があり、グループの縦リストにはドラッグ操作とキーボード操作（修飾キー＋矢印）がある。

同じ「並び替え」に対して2通りの操作体系が並存しており、利用者は画面ごとに操作を覚え直す必要がある。またカードの上下移動ボタンは各カードの横幅を占有しており、名前と値の表示領域を狭めている。狭いサイドパネルでは、グループのタブから三点リーダーを撤去して幅を空けたのと同じ理由で、この占有が効いてくる。

カードの上下移動ボタンを撤去し、グループの縦リストと同じ「ドラッグ操作とキーボード操作」の2手段に統一する。キーボードからの到達性は、カード自体をフォーカス可能にして修飾キー＋矢印で並び替えられるようにすることで維持する。

## EARS形式要件

When 利用者が項目カードにフォーカスを移して並び替えのキー操作を行ったとき,
the system shall そのカードを1つ上または1つ下の位置へ移動して順序を永続化する,
グループの縦リストと同じキー操作・同じ挙動にし、移動後もそのカードにフォーカスを保つ。

When 利用者が項目カードにフォーカスを移して決定キーを押したとき,
the system shall そのカードの値をクリップボードへコピーする,
ポインタでカードを押したときと同じ結果にする。

While 項目一覧が表示されている間,
the system shall 各カードに上下移動ボタンを表示しない,
並び替えの操作手段をドラッグ操作とキーボード操作の2つに限定し、カードの表示領域を名前と値に充てる。

## 詳細要件

- 項目カードをキーボードでフォーカスできるようにする。フォーカス表示は既存のDADSフォーカス表現（[[req-000008]]）をそのまま用いる。
- フォーカスしたカードで決定キーを押すと値がコピーされる。ポインタでカードを押したときと同じ結果になる。
- フォーカスしたカードで、1つ上・1つ下へ移動させるキー操作を提供する。**グループの縦リスト（[[req-000011]]）と同じキーを割り当てる。**
- 移動のたびに順序を永続化し、移動後もフォーカスは移動したカードに残す。
- 各カード左端の上下移動ボタンを撤去する。カードに残る操作要素はコピーボタンと三点リーダーのみとする。
- 検索で絞り込んでいる間、および選択モード中は、キーボードによる並び替えも無効にする（既存のドラッグ操作と同じ条件）。
- グループの縦リストの並び替え（[[req-000011]]）と、判定条件・キー・フォーカスの挙動を揃える。

## ユースケース

1. 利用者がキーボードで項目カードにフォーカスを移す。
2. 並び替えのキー操作を繰り返し、そのカードを一覧の先頭まで移動させる。
3. 別のカードにフォーカスを移し、決定キーを押して値をコピーする。
4. カードの表示を確認すると、上下移動ボタンがなくなった分だけ名前と値の表示幅が広い。

## 技術的制約

- 並び替えの永続化は既存の`ItemRepository`の並び替えAPIをそのまま使う。storage層の変更は不要。
- 並び順の組み替えとキーボード操作の判定は、グループの縦リストで実装済みの仕組み（[[req-000011]]）を流用する。同じ振る舞いを2箇所に書き分けない。
- カードをフォーカス可能にする際、既存のポインタ操作の判定（押した位置からの移動距離でタップと並び替えを区別する）を壊さないようにする。

## エッジケース

- 先頭のカードで上へ移動、末尾のカードで下へ移動するキー操作を行った場合は、順序を変更せず何も起こらない。エラーも表示しない。
- 一覧に表示されている項目が1件以下の場合、並び替えのキー操作は順序を変えない。
- 検索で絞り込んでいる間はキーボードによる並び替えを行わない。絞り込みを解除すれば行える。
- 選択モード中はキーボードによる並び替えも決定キーによるコピーも行わない（選択モード中の個別操作制限[[req-000009]]と整合させる）。
- カード内のコピーボタン・三点リーダー・チェックボックスにフォーカスがある間は、並び替えのキー操作を並び替えとして解釈しない。

## 成功基準

- 項目一覧に上下移動ボタンが0件になる。
- キーボード操作のみで、任意の項目を一覧の先頭へ移動できる。
- キーボード操作のみで、任意の項目の値をコピーできる。
- 項目カードとグループの縦リストで、並び替えに割り当てられたキーが同一である。
- 検索絞り込み中および選択モード中は、キーボードによる並び替えが100%行われない。
- 上下移動ボタンの撤去によってカードの名前・値の表示幅が広がり、既存のポインタ操作（ドラッグでの並び替え、タップでのコピー）に回帰が0件である。
